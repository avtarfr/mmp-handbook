The unit cites "§17.1, the Sturm-Liouville eigenfunctions as a complete orthogonal set and the mean-square convergence of the expansion, pp. 426-430" and "the completeness (closure) relation ... p. 451". 2. [blocking] `:::application` block (line 199): the closure relation is misquoted. The unit writes $\sum_n \hat y_n^*(x)\hat y_n(z) = \delta(x-z)$. RHB's (17.28), p. 563, is $\rho(z)\sum_n \hat y_n(x)\hat y_n^*(z) = \delta(x-z)$ — the weight function $\rho$ of the Sturm-Liouville problem is part of the identity, and RHB adds (17.29) that $\rho(z)$ may be replaced by $\rho(x)$. Dropping $\rho$ makes the stated identity false for any problem with a non-trivial weight (e.g. the Bessel/Legendre cases the unit's other cross-references point to). The conjugation is also on the other argument than RHB's, which is harmless for the symmetric case but is not what the source prints. Fix: write $\rho(z)\sum_n \hat y_n(x)\hat y_n^*(z) = \delta(x-z)$, or state explicitly that the normalisation $\rho \equiv 1$ is being assumed.

4. [minor] `:::remark`, fifth bullet (line 161): "Non-separable Hilbert spaces ... do occur, for instance the almost-periodic functions with $(f,g) = \lim_{T\to\infty}(2T)^{-1}\int_{-T}^{T}f\bar g$".
