## Findings
1. [source] statement "What makes an orthonormal family a basis" (line 78) and remark (line 154): the two sources are in tension about the word "basis" for the monomials. Hassani Thm 7.2.3 (p. 222) says $\{x^k\}$ *is a basis* of $L^2_w(a,b)$ and writes $f=\sum\alpha_kx^k$; Stakgold and Holst (p. 276, Exercise 4.6.7, p. 288) say the same set spans but is not a Schauder basis and that almost no $L^2$ function is a power series. Both are reported faithfully and the remark draws the distinction, so this is not a failure; recorded with `tools/discrepancy.mjs` against hassani-2013. Fix (optional): in the statement block add "basis in the spanning sense" when relaying Hassani, with a pointer to the fourth bullet of the remark.
2. [minor] statement (line 72): "Every Hilbert space $H \ne \{0\}$ has an orthonormal basis" is weaker than Folland Prop. 5.28 ("Every Hilbert space has an orthonormal basis"), which the unit's own empty-family convention (definition, line 43) already covers. The restriction is harmless but makes the unit look as if it disagreed with the cited proposition. Fix: drop "$\ne\{0\}$" and point at the convention, or say explicitly that the case $H=\{0\}$ is the empty basis by convention.
3. [minor] proof "Bessel's inequality..." step 4 (line 104): the inequality chain is written $\sum_F |(u,e_\alpha)|^2 > N/n^2 > \|u\|^2$, but the first relation is only $\ge$ if some coefficient equals exactly its bound; the set $A_n$ is defined with a strict inequality $|(u,e_\alpha)|>1/n$, so each term is $>n^{-2}$ and the strict sign is in fact correct. No change needed; noted only because the step reads as if $N>n^2\|u\|^2$ had to be strict, which the choice "choose an integer $N > n^2\|u\|^2$" supplies. No fix required.
