## Findings
1. [minor] :::example[A pendulum measurement of $g$], step 4: "the discrepancy is $+0.0041\ \mathrm{m\,s^{-2}}$". Computing from the raw inputs, $g = 4\pi^2(1.000)/(2.006)^2 = 9.810652192$, so $g - 9.80665 = 0.004002$, i.e. $+0.0040$, not $+0.0041$. The $0.0041$ comes from subtracting with the already-rounded $9.8107$. (The companion figure "$0.09$ standard errors" is right: I get $0.004002/0.043770 = 0.0914$.) Fix: $+0.0040\ \mathrm{m\,s^{-2}}$.
2. [minor] :::remark, the second-order formulas: "$V[Y] \approx f'(\mu)^2\sigma^2 + \tfrac12 f''(\mu)^2\sigma^4$". This holds for a *normal* input (it uses $\mathbb{E}[\delta^3] = 0$ and $\operatorname{var}(\delta^2) = 2\sigma^4$); for a general distribution the $O(\sigma^4)$ coefficient involves the third and fourth central moments and there is also an $f'f''\mathbb{E}[\delta^3]$ term at order $\sigma^3$. The bias formula $\mathbb{E}[Y] \approx f(\mu)+\tfrac12f''\sigma^2$ is distribution-free at that order, so only the variance line needs the caveat. (I checked the normal case against the unit's own $X\sim N(1,0.5^2)$, $Y=X^2$ example: the formula gives $4(0.25) + \tfrac12(4)(0.0625) = 1.125$, which is the exact variance -- so the formula is right where it is used.) Fix: add "for normally distributed inputs".
3. [minor] :::remark, the $X^2$ example: "the error bar is only $6\%$ low, but the central value is $25\%$ low". Both percentages are taken relative to the *linearised* value rather than the true one; measured against the exact answers they are $5.7\%$ and $20\%$. Internally consistent, but a reader will compute the other pair. One word ("low by $25\%$ of the linearised value") settles it.
4. [minor] :::statement, (P3): the hypothesis is stated as "the linearisation is a good approximation to $f_k$ over the region where $X$ has its probability", with the precision deferred to the remark. That is honest, but it means the displayed result is not a theorem as stated -- only the affine case is. The block says so ("to first order", and the Exactness paragraph), so this is a presentational point rather than an error; it would read better as "the following are the first-order approximations, exact when every $f_k$ is affine".
