## Findings
1. [blocking] definition[Test functions] (the displayed formula for $\varphi_\ast$): the exponent is not inverted. As typeset, `\exp\bigl(\lvert x\rvert^2 - 1\bigr)^{-1}` renders as $\exp(\lvert x\rvert^2-1)^{-1}$, which reads as the reciprocal $e^{1-\lvert x\rvert^2}$ — a function that is nowhere zero, has no compact support, is not a test function, and takes the value $1$ (not $e^{-1}$) at $\lvert x\rvert=1$ and $e$ at $x=0$. The prose two lines later gives the intended function correctly as $\exp\bigl(-1/(1-\lvert x\rvert^2)\bigr)$, and the proof of part (3) uses $\psi_a(0)=\varphi_\ast(0)=e^{-1}$, so the displayed formula contradicts the rest of the unit. Stakgold and Holst's (2.1.2) (p. 94) is $\exp\bigl(1/(\lvert x\rvert^2-1)\bigr)$. Fix: write $\varphi_\ast(x)=\exp\bigl(\tfrac{1}{\lvert x\rvert^2-1}\bigr)$ (or $\exp\bigl(-\tfrac{1}{1-\lvert x\rvert^2}\bigr)$) for $\lvert x\rvert<1$, so the exponent is unambiguously the reciprocal.
2. [blocking] proof (part (3), second bullet about $\psi_a$): the stated reason is false. The text says "$0 \le \psi_a \le e^{-1}$ everywhere, since $\lvert x/a\rvert^2 - 1 \le -1$ on the support". On the support $\lvert x/a\rvert<1$ one has $-1 \le \lvert x/a\rvert^2-1 < 0$, so the asserted inequality holds only at $x=0$. The bound $\psi_a\le e^{-1}$ is true, but the inequality that gives it is $1/(\lvert x/a\rvert^2-1) \le -1$. This is the same dropped reciprocal as finding 1, and the bound is used to get the displayed estimate $\lvert\int f\psi_a\rvert \le e^{-1}\int_{\lvert x\rvert\le a}\lvert f\rvert$. Fix: replace the justification by "since $1/(\lvert x/a\rvert^2-1) \le -1$ on the support".
