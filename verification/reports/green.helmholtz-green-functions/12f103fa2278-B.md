## Findings
1. [blocking] example "A uniform source in a slab, in one dimension", item 6 (line 224): "A source whose width is a whole number of half-wavelengths is silent — the two edges interfere destructively." The source is $f=1$ on $\lvert x\rvert<L$, so its width is $2L$, and the unit's own formula makes the radiated amplitude $\lvert\sin kL\rvert/k^2$. Silence therefore requires $kL = n\pi$, i.e. $L$ a whole number of half-wavelengths, i.e. the *width* a whole number of whole wavelengths. As stated the claim is false, and the counterexample is two sentences earlier in the same item: at $k=1$, $L=\pi/2$ the width is $\pi = \lambda/2$, one half-wavelength, and the unit has just computed that the outgoing amplitude there is exactly $1$ — the largest it can be, not zero. Fix: "A source whose width is a whole number of *wavelengths* is silent", or equivalently "whose half-width is a whole number of half-wavelengths".
2. [minor] example "A spherical shell source in three dimensions", item 6 (line 258): "A breathing sphere whose radius is a half-integer number of wavelengths radiates nothing." Silence requires $\sin kb = 0$, i.e. $b = n\lambda/2$ for any positive integer $n$. Taking "half-integer number of wavelengths" in its usual sense ($b=(n+\tfrac12)\lambda$) the implication is true but describes only the odd $n$; it misses $b = \lambda, 2\lambda,\dots$, which are equally silent. The instance actually computed ($b=\pi$, $k=1$, so $b=\lambda/2$) is one of the odd cases, so nothing in the worked numbers is wrong. Fix: "whose radius is a whole number of half-wavelengths".
