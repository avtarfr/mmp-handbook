## Findings
1. [minor] statement, part 2, last sentence (line 72): "$\lambda=0$ is always an eigenvalue of $\mathcal{K}$ itself, of infinite multiplicity when the interval is infinite-dimensional". An interval has no dimension; what is meant is "when $L^{2}(a,b)$ is infinite-dimensional", i.e. for every non-degenerate interval. As written the qualifier is empty and slightly garbled. The substance is right: $\{u:\int\psi_ju=0\ \forall j\}$ has codimension $n$, so it is infinite-dimensional and $\mathcal{K}$ kills it. Fix: "of infinite multiplicity, since $L^{2}(a,b)$ is infinite-dimensional".
2. [minor] definition (line 41): "has range contained in $\operatorname{span}\{\phi_1,\dots,\phi_n\}$ and so has rank $n$ as a linear map". Containment on its own gives rank $\le n$; equality needs the independence of the $\psi_j$ (which makes $u\mapsto(\int\psi_ju)_j$ onto $\mathbb{C}^n$), supplied two sentences earlier but not invoked here. Fix: "and, because the $\psi_j$ are independent, range exactly that span, so it has rank $n$".
3. [minor] frontmatter, arfken-2013 `loc` (line 11): "Exercise 21.2.16, p. 1063" is listed, and the exercise does exist on p. 1063 and treats a degenerate kernel — but it is about the equation of the *first* kind ($f=\mathcal{K}\varphi$: solvability iff $f\in\operatorname{span}\{M_i\}$, plus the $\psi\perp N_i$ freedom), which this unit never discusses. Nothing in the unit draws on it. Fix: drop the locator, or add the first-kind case to the statement, where it would fit part 2's null-space clause well.
