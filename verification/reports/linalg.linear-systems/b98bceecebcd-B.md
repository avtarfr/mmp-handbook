## Findings
1. [minor] method, step 6 (line 74): "The result `[U | c]` is in row echelon form" is false for the augmented matrix as the unit defines row echelon form ("every zero row lies below every nonzero row"). The elimination only seeks pivots in columns `1..n` (step 2 stops at `j > n`), so the rows below the last pivot are left in whatever order the pivoting happened to leave them, and a fully zero row can sit above a row of the form `(0, ..., 0 | c)` with `c != 0`. Concrete case: `A = [[1,0],[0,0],[0,0]]`, `b = (1,0,1)`. The recipe pivots once in column 1, then finds column 2 zero in rows 2-3 and stops, returning `[[1,0|1],[0,0|0],[0,0|1]]` - row 2 is zero and row 3 is not. The *first n columns* `U` are in row echelon form, which is all steps 7-9 need, so nothing downstream breaks. Fix: "The first `n` columns of the result form a matrix `U` in row echelon form" (and keep step 7 scanning all rows, as it already does).
2. [minor] method, steps 2-4 (lines 70-72): `k` names two different things. In step 2 it is the chosen pivot row ("say row k"), and in step 4 it is the elimination loop index ("For each k > i"). Step 4 also writes the multiplier as `A_kj/p`, where `A` must be read as the current working array rather than the input matrix `A` of the preamble. Fix: use a second letter for the loop in step 4 (e.g. "for each row `l > i`") and write the entries of the working array as `M_lj` or state once that `A` denotes the current contents of the augmented array.

- Calculations, with `.venv/bin/python` (numpy/scipy). I implemented the nine steps literally as written, including the modulus-largest pivot choice, the `j <- j+1` skip, step 7's consistency scan and step 8's displayed back-substitution formula, and ran it on:
  - square nonsingular `A = [[2,1,-1],[-3,-1,2],[-2,1,2]]`, `b = (8,-11,-3)`: returns rank 3, `x = (2, 3, -1)` exactly, empty null-space basis. Correct.
  - rank-deficient but consistent `A = [[1,2,3],[2,4,6],[1,1,1]]`, `b = (6,12,3)`: returns rank 2 (numpy's `matrix_rank` agrees), residual `||Ax_p - b|| = 0`, and the one returned null-space vector `v` satisfies `||Av|| = 0`. Correct.
  - inconsistent `A = [[1,1],[2,2],[1,0]]`, `b = (1,3,0)`: step 7 fires and the recipe reports no solution; rank 2, matching `matrix_rank`. Correct.
  - wide `A` random 2x5: returns rank 2, `n - r = 3` free variables, 3 null-space vectors with `max ||Av|| = 4.4e-16`, and `||Ax_p - b|| = 0`. Correct, and it confirms part 3 of the solvability statement.
  - Back-substitution formula checked algebraically: row `i` of `U` reads `sum_k U_ik x_k = c_i` with `U_ik = 0` for `k < j_i`, giving exactly `x_{j_i} = (c_i - sum_{k > j_i} U_ik x_k)/U_{i j_i}`. The claim that every `x_k` on the right is already known holds because `k > j_i` is either free or a pivot column `j_l` with `l > i`.
  - "the entries of U to grow by a factor `2^(n-1)` ... and matrices attaining that bound exist": reproduced with the Wilkinson matrix (unit lower triangular with `-1` below the diagonal and a last column of ones) under `scipy.linalg.lu`. Growth `max|U|/max|A|` came out 8.0 for n = 4, 128.0 for n = 8 and 2048.0 for n = 12, i.e. exactly `2^(n-1)` = 8, 128, 2048. The bound and its attainability are both right.
  - "about (2/3) n^3 operations for a square system": agrees with the standard `2n^3/3` flop count for Gaussian elimination / LU.
  - Fredholm part 1 recomputed by hand in the unit's own convention `(u,v) = sum_i u_i conj(v_i)`: `(Ax, v) = sum_i sum_j A_ij x_j conj(v_i)` and `(x, A*v) = sum_j x_j conj(sum_i conj(A_ij) v_i) = sum_j x_j sum_i A_ij conj(v_i)`. Equal, so the conjugate transpose is the right adjoint for this convention and the remark's warning about the plain transpose is correct.
  - Fredholm part 2's count `m - rank A`: `dim ker A* = m - rank A* = m - rank A` by part 2 of the rank statement. Consistent.
  - Fredholm part 4's dimensions: `dim ker A* = d` gives `rank A = n - d`, so `im A` has dimension `n - d` and the solution set has dimension `n - rank A = d`. Both numbers in the unit are right; checked on 200 random integer square matrices up to 5x5 that `dim ker A^T = n - rank A` in every case.
