[blocking] statement "The induced norm and the two basic inequalities", part 2 (line 87), with the remark bullet "Equality in Cauchy-Schwarz" (line 107): the stated equality condition is false as written, because it is phrased on the *set* `{x, y}` and the handbook's own definition of a linearly dependent set makes `{x, x}` independent.

   Counterexample. Take `V = R` with `(x,y) = xy`, and `x = y = 1`. Then `|(x,y)| = 1 = ||x|| ||y||`, so equality holds. But `{x, y} = {1}`, a one-element set, and by the definition in the prerequisite unit :ref[Vector spaces and bases]{to=linalg.vector-spaces-bases} ("S is linearly dependent if `sum a_i v_i = 0` for some **distinct** `v_1, ..., v_k` in S and some scalars not all zero") a singleton `{v}` with `v != 0` is linearly *independent*. So the "only if" direction fails for every `x = y != 0`, in every inner product space. Verified numerically for `x = y = (1,2)` in `R^2`: `|(x,y)| = 5.0` and `||x|| ||y|| = 5.0`.

   This is not a quarrel with the source. `kreyszig-1978` Lemma 3.2-1(a), p. 137 does say "if and only if {x, y} is a linearly dependent set", so the unit reports it faithfully, and I have recorded the source's imprecision separately (`node tools/discrepancy.mjs add linalg.inner-product-spaces kreyszig-1978 "section 3.2, Lemma 3.2-1(a), p. 137" ...`). What makes it blocking here is internal: the handbook pins the definition of set-dependence down in a listed prerequisite, that prerequisite goes out of its way to warn that "a repeated entry makes a tuple dependent, although the underlying set may be independent", and this unit's remark then argues *for* the set reading - "The condition is on the *set* `{x,y}`, so it is symmetric in x and y" - which is our own gloss, not Kreyszig's. Under `docs/contributing/source-authority.md` that is "a definition used in a way it does not permit", which stays blocking.

   Fix: state the condition on the pair rather than the set. Either "with equality exactly when `x` and `y` are linearly dependent as a pair, that is, when one of them is a scalar multiple of the other" or, in the same shape as part 3, "with equality exactly when `y = 0` or `x = cy` for some `c` in F". Both are symmetric in `x` and `y` (if `y = kx` with `k != 0` then `x = k^-1 y`; if `x = 0` take `c = 0`), so the remark's symmetry observation survives verbatim - it just needs to stop resting on the word "set". The contrast drawn with Hassani's one-directional Thm 2.2.7 is correct and worth keeping.
