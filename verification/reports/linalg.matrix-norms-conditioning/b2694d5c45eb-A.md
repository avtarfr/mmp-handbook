2. [minor] definition "Induced matrix norm" (line 31): "Induced norms satisfy $\|I\| = 1$" is true only when the same norm is used on domain and codomain, whereas the sentence just above deliberately allows two different norms. The same caveat makes the Frobenius argument on line 38 ($\|I_n\|_F = \sqrt n$) an argument against $\|\cdot\|_F$ being induced by a *single* norm; it is in fact not induced by any pair, but that needs the rank-one computation $\|uv^\dagger\| = \|u\|\,\|v\|_*$. Fix: say "with the same norm on both sides" for $\|I\|=1$, and either strengthen or weaken the Frobenius claim to match its justification.
3. [minor] definition "Induced matrix norm" (line 31): "Taking the vector norms $\|x\|_q = (\sum_i|x_i|^q)^{1/q}$" does not cover $q=\infty$, yet $\|A\|_\infty$ is read off immediately afterwards. Fix: add "and $\|x\|_\infty = \max_i|x_i|$".
