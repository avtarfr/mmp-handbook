[blocking] statement "When the product rule holds", item 4 (line 80): the Baker-Campbell-Hausdorff identity $\exp(A)\exp(B) = \exp\bigl(A + B + \tfrac12[A,B] + \cdots\bigr)$ is asserted "in general", for arbitrary $n \times n$ complex $A$ and $B$, with no convergence or smallness hypothesis. The BCH series of iterated commutators does not converge for all $A, B$; the standard hypothesis is a smallness condition such as $\|A\| + \|B\| < \log 2$ in a submultiplicative norm. The second sentence, "the discrepancy is of second order in the size of $A$ and $B$", is the correct content but leaves "size" and "second order" unquantified, which is exactly the failure mode `docs/contributing/phase-concepts.md` singles out ("'small' is not '$|x| < \delta$ for some $\delta$ depending only on ...'"). The block is `provenance=original`, so the imprecision is ours. It also sits badly beside items 1-3, whose whole point is that this statement block gives exact conditions. Fix: state it with the hypothesis, e.g. "if $\|A\| + \|B\|$ is small enough (for instance $\|A\| + \|B\| < \log 2$ in a submultiplicative norm) then $\exp A \exp B = \exp(C)$ with $C = A + B + \tfrac12[A,B] + \cdots$, the series of iterated commutators converging"; and replace the "second order" clause by the quantified version, $\exp(A)\exp(B) = \exp\bigl(A + B + O(\varepsilon^2)\bigr)$ for $\|A\|, \|B\| \le \varepsilon$.
