## Findings
1. [minor] remark "Where the hypotheses are used", final bullet "The axiom of choice" (line 194): the
   parenthetical "in particular if $X$ is separable, where one can adjoin the elements of a countable
   dense set" is not correct as written, and is not in Kreyszig. Adjoining a countable dense set one
   vector at a time exhausts a *dense* subspace of $X$, not $X$ itself, so it does not put $X$ in the
   form $X=\bigcup_j Z_j$ that the preceding clause requires. (Kreyszig pp. 217-218 says only "if $X$
   has no such representation, we do need Zorn's lemma"; separability is not mentioned.) Note also
   that part (a), the setting of Step 4, has no norm on $X$, so "separable" is undefined there.
   Fix: either drop the clause, or restrict it to the normed form (c) and add the missing step --
   for separable $X$ one extends by induction to the dense subspace and then by continuity, which is
   available because the extension obeys $|F|\le\|f\|_{Z^{*}}\|\cdot\|$.
2. [minor] example "A distance, and the functional that detects it", Step 4 (line 234): the sentence
   "So the value $3$ is attained, only by the $f$ above, and no larger value is possible" overstates
   what the displayed argument shows. Setting $3a+b=3$ and deriving $a=1,b=0,c=1$ rules out other
   maximisers *on the level set $3a+b=3$*; it does not by itself exclude $3a+b=v>3$. (The claim is
   true: $b=v-3a$ gives $c=2v-5a$, and $|c|\le1$ forces $a\ge(2v-1)/5$, which with $|a|\le1$ gives
   $v\le3$.) Fix: run the same elimination with a general value $v$, or quote the one-line bound
   $|f(x)|=|f(x-tu)|\le\|f\|_\infty\|x-tu\|_1$ minimised over $t$.
