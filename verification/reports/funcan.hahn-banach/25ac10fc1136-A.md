## Findings
1. [minor] example (line 234): Step 4 is headed "The maximum really is $3$" and concludes "the value $3$ is attained, only by the $f$ above, and no larger value is possible", but the computation shown only analyses the level set $3a+b=3$ (it substitutes $b=3-3a$ and derives $a=1$). That establishes uniqueness of the maximiser among value-$3$ points; it does not rule out a feasible point with $3a+b>3$. The claim is true — for $3a+b=v$ one gets $b=v-3a$, $c=2v-5a$, and $|b|\le 1$, $|c|\le 1$, $a\le 1$ force $v\le 3$ (confirmed numerically: `linprog` gives max $=3$ at $(a,b,c)=(1,0,1)$) — but the argument as printed does not reach it. Fix: either run the same substitution with a general value $v$, or add the one-line general bound: if $\|f\|\le 1$ and $f|_M=0$ then $f(x)=f(x-tu)\le\|x-tu\|$ for every $t$, hence $f(x)\le\delta$.
2. [minor] statement "Consequences" (line 87): the closing attribution says "part 4 is Reed and Simon's Thm III.4". Reed and Simon state Thm III.4 for a *Banach* space (p. 74: "Let $X$ be a Banach space"), whereas part 4 is asserted here for an arbitrary normed space. The normed-space source is Folland's Thm 5.8(d) (p. 159, "Let $X$ be a normed vector space"), which is cited in the block header but not in this sentence. Fix: attribute part 4 to Folland Thm 5.8(d) and add that Reed and Simon's Thm III.4 assumes completeness.
3. [minor] remark (line 190): "the real form (a) is false as stated if one tries to conclude $|F|\le p$ from $F\le p$ for a merely sublinear $p$". Form (a) is not false; what fails is the attempted strengthening. The counterexample given ($p(t)=t$, $F(t)=t$ on $\mathbb{R}$) is correct. Fix: reword to "form (a) does not yield $|F|\le p$ for a merely sublinear $p$".
4. [minor] application (line 250): "$(L^{p})^{*} = L^{q}$ for $1 \le p < \infty$" is stated with no hypothesis on the measure space. The $p=1$ case requires semifiniteness (or $\sigma$-finiteness); Folland's own §6.4, p. 191 — cited two paragraphs earlier in this same block — exhibits a measure for which the dual of $L^{1}(\mu_{0})$ is $L^{\infty}(\mu) \ne L^{\infty}(\mu_{0})$, and notes that $g \mapsto \phi_{g}$ is not injective when $\mu$ is not semifinite. Fix: restrict to $1<p<\infty$, or add "for a $\sigma$-finite measure".
5. [source] application (line 250): the unqualified "$1 \le p < \infty$" faithfully follows Reed and Simon, Example 1, §III.2, p. 73 ("The duality statements in this example hold for $L^p(X,d\mu)$ where $(X,\mu)$ is a general measure space", with a caveat only for $p=\infty$).
