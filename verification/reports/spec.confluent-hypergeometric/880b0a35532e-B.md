## Findings

1. [source] definition (line 47): Arfken, Weber and Harris's Eq. (18.142), p. 917,
   does print `Gamma(a)Gamma(-c)` in the second denominator of U, as the unit says,
   and that denominator is wrong: with `Gamma(2-c)` the combination is exactly the
   standard Tricomi function (DLMF 13.2.42, reached from
   U = Gamma(1-c)/Gamma(a-c+1) M + Gamma(c-1)/Gamma(a) x^{1-c} M(a-c+1,2-c,x) by the
   reflection formula), and only then do the two poles cancel so that U has the finite
   limit at integer c that Arfken, Weber and Harris themselves claim one line later.
   The unit follows Riley, Hobson and Bence, states the clash, and is faithful to both
   books, so this is not a defect of the unit. Recorded with
   `node tools/discrepancy.mjs add spec.confluent-hypergeometric arfken-2013
   "Sect. 18.6, Eq. (18.142), p. 917" ...`.

2. [minor] definition (line 47): "whose version is the one that reduces to a finite
   multiple of the standard U". It is not a multiple — the Riley, Hobson and Bence
   combination *is* the standard U exactly (verified against DLMF 13.2.42 by the
   reflection-formula rewriting above). Fix: say "is the standard U" rather than "a
   finite multiple of" it. The same sentence says "the discrepancy is recorded"; at
   the time of this review `verification/discrepancies.md` held no entry for this unit,

- **Counterexample search.** Statement 1: the exclusions are exactly right — c in
  {0,-1,-2,...} kills (c)_n in the recurrence; c = 1 makes y_2 = y_1 identically;
  c in {2,3,4,...} puts 2-c in the forbidden set so y_2 is undefined. Entirety of M
  checked from the ratio (a+n)x/[(c+n)(n+1)] -> 0, which fails only on the excluded
  c. Statement 3: (IM) needs a > 0 at t = 0 and c-a > 0 at t = 1; both bite, and the
  integral genuinely diverges if either fails. (IU) needs Re x > 0 for convergence at
  t = infinity; tested with x = -1, where the integral diverges. Termination tested at
  a = 0, a = -3: polynomial of degree 3 for the latter, and I confirmed that making c
  a negative integer does *not* terminate, as the remark claims (it destroys the
  series), by direct inspection of (c)_n.
  Statement 2's confluence limit: `(b)_n/b^n -> 1` for each fixed n, verified; the
  intermediate equation's singular points sit at z = 0, b, infinity, and the unit's
  caveat about keeping a, c, z fixed is Hassani's and is correct.
