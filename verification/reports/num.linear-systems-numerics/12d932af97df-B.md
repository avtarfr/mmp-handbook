## Findings
1. [minor] application, "Least squares and data fitting" (line 360): "Fitting a degree-$12$ polynomial in the monomial basis on $[0,1]$ uses $13$ coefficients, so the normal matrix is the $13\times13$ Hilbert matrix" conflates the discrete fit introduced one sentence earlier ($A^{\mathsf T}A$ for $m$ data points, entries $\sum_i x_i^{\,j+k}$) with the continuous one (entries $\int_0^1 x^{j+k}\,dx = 1/(j+k+1)$). It is the continuous Gram matrix that is exactly Hilbert; the discrete one only approaches it as the abscissae fill $[0,1]$. The condition numbers quoted are those of the genuine Hilbert matrices and are right, so the conclusion stands; only the "so" is too strong. Fix: "the normal matrix is the $13\times13$ Hilbert matrix (exactly so for the continuous $L^2[0,1]$ fit, and close to it for data spread over the interval)".
2. [minor] example, Part 3 table (line 348): the printed $\|r^3\|_2 = 4.4\times10^{-17}$ is a rounding-noise quantity, not a reproducible number — my run of the same algorithm gave $6.2\times10^{-17}$, and any change of summation order or BLAS will move it again. The text's own gloss ("at the rounding level") is the honest statement. Fix: print "$<10^{-16}$" rather than a two-digit value, or say "about $5\times10^{-17}$ in our run".
3. [minor] statement "Gaussian elimination", part (i) (line ~63): "a sufficient condition is that every leading principal submatrix $A_{1:k,1:k}$ is nonsingular, $k = 1,\dots,n$" is correct but weaker than it needs to be — $k=1,\dots,n-1$ already suffices for the factorization to exist, with $k=n$ adding only the nonsingularity of $A$ itself. Fix: say $k=1,\dots,n-1$, which is the sharp form and makes the singular-$A$ parenthesis that follows read better.
