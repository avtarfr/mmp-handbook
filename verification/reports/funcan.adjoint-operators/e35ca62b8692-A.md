## Findings
1. [minor] statement "The three classes", part 3 (line 74): "$ST$ is self-adjoint if and only if
   $ST = TS$" does not carry its hypothesis. Read on its own the claim is false — $S$ any operator and
   $T = I$ commute, and $ST = S$ need not be self-adjoint. The heading ("Stability of the class") and
   the flanking clauses make the intent clear, and the proof (line 140) states the hypothesis
   explicitly, so this is wording, not an error. Fix: "if $S$ and $T$ are self-adjoint, $ST$ is
   self-adjoint if and only if $ST = TS$", matching Kreyszig's Thm 3.10-4, p. 204.
2. [minor] prerequisites: method step 2 (line 180) derives $k^*(x,y) = \overline{k(y,x)}$ by naming
   Fubini's theorem (:ref{to=measure.fubini-tonelli}), and that formula is then used in example 1 to
   declare $K$ self-adjoint; `measure.fubini-tonelli` is in no entry of `prereqs` and is not reachable
   from one. Example 2 (line 269) likewise invokes Parseval from
   :ref{to=funcan.orthonormal-bases}, which is reachable only through `funcan.bounded-operators`.
   Fix: list `measure.fubini-tonelli` and `funcan.orthonormal-bases`, as the sibling
   `funcan.unbounded-operators` lists `funcan.projection-theorem` and `funcan.riesz-representation`
   explicitly rather than relying on the chain through `funcan.adjoint-operators`.
3. [minor] example 2 (line 269): $\|Pu\|^2$ is printed as $0.8105695 + 0.0900633 = 0.9006328$; the sum
   of the rounded addends is right, but the value itself is $0.90063274$, which rounds to
   $0.9006327$. (The following $\|u - Pu\| = 0.3152257$ is computed from the exact value and is
   correct; so is the $90.06\%$.) Fix: print $0.9006327$.
4. [minor] definition block (line 41): "Physicists write $T^{\dagger}$ for $T^*$ and, with the inner
   product conjugate-linear in the *first* slot, state the same equation as
   $\langle Tx\mid y\rangle = \langle x\mid T^{\dagger}y\rangle$ ...; the operator defined is the same."
   The conclusion is right — with $\langle a\mid b\rangle = (b,a)$ one gets
   $\langle Tx\mid y\rangle = \overline{(Tx,y)} = \overline{(x,T^*y)} = \langle x\mid T^*y\rangle$ —
   but the unit asserts it without the one-line reason, and this is exactly the place a reader
   crossing between Kreyszig's and Hassani's conventions needs it. Fix: add the conjugation step.
