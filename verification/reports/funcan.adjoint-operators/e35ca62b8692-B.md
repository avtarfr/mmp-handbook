## Checked
- Counterexample search: probed each class statement for the usual failures. $(Tx,x)$ real $\Rightarrow$ $T=T^*$ does need complex scalars — the $90^{\circ}$ rotation of $\mathbb{R}^2$ has $(Qx,x)=0$ for all $x$ with $Q \ne 0$, as the remark says. "Isometric $\Rightarrow$ unitary" does need surjectivity — the right shift on $\ell^2$ has $S^*S = I$ but $SS^*$ is the projection off $e_1$. "$P^2=P$ $\Rightarrow$ $\|P\|=1$" does need $P = P^*$ — $\bigl(\begin{smallmatrix}1&1\\0&0\end{smallmatrix}\bigr)$ is idempotent with singular values $\{\sqrt2,0\}$, so $\|P\| = \sqrt2$, exactly as claimed. $T = 2iI$ is normal, not self-adjoint ($T^* = -2iI$) and not unitary ($T^{-1} = -\tfrac{i}{2}I \ne T^*$) — correct. The norm proof's identity $(Ty_1,y_1)-(Ty_2,y_2) = 2[(Tv,w)+(Tw,v)] = 4\|Tz\|^2$ and the parallelogram bound $4K\|Tz\|$ both verify with $v = \|Tz\|^{1/2}z$, $w = \|Tz\|^{-1/2}Tz$. The splitting uniqueness argument ($T_1-S_1 = i(S_2-T_2)$, adjoint gives the negative, add) is sound. No counterexample found.
