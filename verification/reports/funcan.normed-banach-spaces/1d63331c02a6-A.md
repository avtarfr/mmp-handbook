## Findings
1. [minor] statement part 5 (line 73): "the sequences with only finitely many nonzero terms, with any $\ell^p$ norm. Each is a dense subspace of a Banach space and is not closed in it." If "any $\ell^p$ norm" is meant to include $p=\infty$ — part 4 lists $\ell^\infty$ separately, so it is ambiguous — then the reader will naturally read "dense in $\ell^\infty$", which is false: $c_{00}$ is dense in $c_0$, not in $\ell^\infty$. The sentence is literally true as written, since $c_0$ is a Banach space, but it invites the wrong reading. Fix: write "$1\le p<\infty$", or name the ambient space in each case ("dense in $\ell^p$ for $p<\infty$, and in $c_0$ for the sup norm").
