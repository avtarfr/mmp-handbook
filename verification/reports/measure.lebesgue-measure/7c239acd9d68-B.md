## Findings
1. [minor] proof "Lebesgue measure: the five properties", part (d) (line 166): "The case $m(E)=\infty$ follows by doing this on each $E\cap(j,j+1]$ and intersecting." Taken literally this is the wrong construction: the $G_\delta$ hulls $V_j$ of the pieces must be *united* over $j$ at each tolerance, and only the resulting open sets intersected over tolerances; intersecting the $V_j$ gives a set that need not contain $E$. Folland leaves this case to Exercise 25, p. 37. Fix: "for each $k$ choose open $U^{(k)}_j \supseteq E\cap(j,j+1]$ with $m(U^{(k)}_j \setminus E) < 2^{-|j|}/k$, put $U^{(k)} = \bigcup_j U^{(k)}_j$ and $V = \bigcap_k U^{(k)}$."
2. [minor] statement "Not every set can be measured" (line 86): Folland's incompatible triple (p. 19) is countable additivity, invariance under *congruences* (translations, rotations, reflections) and $\mu(Q)=1$; the unit states the stronger theorem with translation invariance alone. That is legitimate — the unit's own proof uses only translations, as Folland's $n=1$ argument does — but a reader comparing with p. 19 will see a different hypothesis. Fix: one clause noting that the source assumes congruence invariance and that translations alone suffice on the line.
3. [minor] proof "Lebesgue measure", (e) (line 170): $m_r(E) = m(rE)$ is compared with $m$ via "the uniqueness clause", but $m_r$ matches $|r|\mu_0$ rather than $\mu_0$ on h-intervals, so the clause is applied to $|r|^{-1}m_r$. Worth one half-sentence, as the translation case just before it is exact.
