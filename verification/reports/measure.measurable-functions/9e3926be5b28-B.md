## Findings
1. [minor] statement "It is enough to test a generating family", part b (lines 58–64), and its proof (line 110): the statement asserts that each of the four ray families tests measurability for $\overline{\mathbb{R}}$-valued $f$ as well, but the proof only shows that $(a,\infty]$ generates $\mathcal{B}_{\overline{\mathbb{R}}}$ and then says "Apply the criterion to each family in turn". Folland p. 45 states only "$(a,\infty]$ or $[-\infty,a)$". The claim is true — e.g. $(a,\infty]=\bigcup_n[a+\tfrac1n,\infty]$ gets $(a,\infty]$ from the closed rays, and $[-\infty,a]=\bigcap_n[-\infty,a+\tfrac1n)$ from the open ones — but the unit does not supply it. Fix: add the one-line generation argument for the other three families in the $\overline{\mathbb{R}}$ case.
2. [minor] note (line 49): "The converse direction is Lusin's theorem". Lusin's theorem gives a closed set off which the measure is small and on which the *restriction* is continuous; producing a continuous function on all of $[0,1]$, which is what Stakgold and Holst's definition demands, also needs the Tietze extension theorem. Fix: say "Lusin's theorem together with Tietze extension".
3. [minor] method (line 207): "A function that is continuous at every point outside a countable set $D$ is measurable too" silently uses $D\in\mathcal{M}$. That is automatic for Borel or Lebesgue on the line (a countable set is Borel) but not in the abstract $(X,\mathcal{M})$ the sentence is phrased in. Fix: add "$D$ being countable, hence Borel".
