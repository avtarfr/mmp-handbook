## Findings
1. [minor] idea (line 119): "an indicator can be bounded below by anything that is small where the event fails and large where it holds" has the inequality the wrong way round. The device used in the proof is that $a\mathbf{1}_A$ is bounded *above* by $h(X)$ (equivalently $\mathbf{1}_A \le h(X)/a$); the clause as written says the indicator dominates $h$. The display in the very next sentence states the correct direction, so the slip is self-correcting, but the sentence should read "bounded above".
2. [minor] statement (line 53): the master inequality is given the extra hypothesis "$X$ a random variable for which $\mathbb{E}(h(X))$ is finite", which Grimmett and Stirzaker's Theorem (7.3.1), p. 363, does not impose and which the unit does not need (the bound is vacuously true when the expectation is infinite). The remark at line 224 ("Markov's inequality is vacuous but not false when $\mathbb{E}|X| = \infty$") is in fact a statement about the version without that hypothesis, so the two blocks are in mild tension. Fix: drop the finiteness hypothesis from the statement, as the source does.
3. [minor] proof (line 187): "We apply the exponential bound not to $S_n$ itself but to the centred and scaled variable" does not describe the step that follows. The display applies the exponential bound to $S_n$ at level $n(p+\epsilon)$; the centring happens one line later, when $e^{-\lambda np}$ is absorbed into the bracket. Fix: reword to "we apply the exponential bound to $S_n$ at the level $n(p+\epsilon)$ and then absorb $e^{-\lambda n p}$ into the bracket, which keeps the algebra symmetric in $p$ and $q$".
4. [minor] remark (line 244): the stationary point $e^{\lambda} = (p+\epsilon)q/\bigl(p(1-p-\epsilon)\bigr)$ and the exponent $D(p+\epsilon\Vert p)$ require $p+\epsilon < 1$, which is not stated (the formula is undefined at $p+\epsilon = 1$). Fix: add "for $0 < p < p+\epsilon < 1$".
5. [minor] remark (line 230) and application (lines 304-312): Jensen's inequality is stated here for $u : \mathbb{R} \to \mathbb{R}$ (following both sources), but is then applied to $\log$ and to $x \mapsto x\log x$, which are finite only on $(0,\infty)$. The conclusions are correct for a positive random variable, but they are not instances of the statement as stated. Fix: say in one clause that the same proof works for a convex $u$ on an interval containing the range of $X$, with the supporting line taken at an interior point.
