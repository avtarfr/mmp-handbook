## Findings
1. [blocking] statement "Which sets are countable, and which are not", item 3 (line 133): as written the item is vacuous, and the content of the cited source is lost. The unit *defines* "countably infinite" by `card(X) = card(N)` (line 104), so "Should $X$ be countably infinite, $\operatorname{card}(X) = \operatorname{card}(\mathbb{N})$" is the implication $P \Rightarrow P$ and asserts nothing. Folland's Prop 0.10(c) (p. 8), which this item cites, is not vacuous, because Folland defines "countably infinite" as "countable but not finite" (p. 7); his claim is that an *infinite set admitting an injection into* $\mathbb{N}$ is in bijection with $\mathbb{N}$. That claim is nowhere stated in the unit as a result, yet it is used: the definition block (line 104) concludes "So every finite set is countable, and a countable set is either finite or countably infinite", where the second clause is exactly Prop 0.10(c) and does *not* follow from the definitions ("So") - it needs the construction behind item 3's second sentence. Fix: state item 3 as "If $X$ is countable and infinite then $\operatorname{card}(X) = \operatorname{card}(\mathbb{N})$; equivalently, an infinite $S \subseteq \mathbb{N}$ admits a bijection onto $\mathbb{N}$", and in the definition block either drop the "So" from the second clause or mark it as forward-referencing that item.
2. [blocking] statement "Which sets are countable, and which are not", item 6 (line 140): the relation $\operatorname{card}(X) > \mathfrak{c}$ is never defined. The definition block (lines 97-100) deliberately defines only $\le$, $=$, $\ge$ and $<$, and states that "$\operatorname{card}(X)$ standing alone is given no meaning here", so the unit's own symbol discipline is violated here. The gap is not harmless: Folland (p. 6) defines $\operatorname{card}(X) > \operatorname{card}(Y)$ to mean "there is a surjection but no bijection from $X$ to $Y$", which is not the reading a reader would guess from the unit's $<$ (injection but no bijection). Fix: add the fourth relation to the definition block, in Folland's sense (p. 6), or restate item 6 with the relations that are defined, e.g. "if $\operatorname{card}(\mathbb{R}) \le \operatorname{card}(X)$ and no bijection $X \to \mathbb{R}$ exists, then $X$ is uncountable".
3. [minor] statement "Cantor's theorem" (lines 121-127): the conclusion is asserted "for every set $X$", but $<$ was defined only "For nonempty sets $X$ and $Y$" (line 95), and the extension to $\emptyset$ at line 102 covers only $\le$ and $\ge$. So $\operatorname{card}(\emptyset) < \operatorname{card}(\mathcal{P}(\emptyset))$ is undefined by the unit's own definitions. (Folland handles this by the blanket convention on p. 6 that all sets in the section are nonempty; the unit drops that sentence.) Fix: either say "for every nonempty set $X$" or extend $<$ to $\emptyset$ explicitly.
4. [minor] remark (line 152): "Item 3 fails for finite $X$" cannot be true of item 3 as stated, since its hypothesis (a bijection onto $\mathbb{N}$) excludes finite sets. The sentence makes sense only against the intended statement in finding 1 ("countable" in place of "countably infinite"), which is how it should be phrased.
