## Findings
1. [minor] statement "Which sets are countable, and which are not", item 3 (line 133): the first sentence is vacuous under the unit's own definitions, and the substantive result it is meant to carry (Folland Prop 0.10(c)) ends up stated nowhere as a theorem. The unit takes *countable* from Folland (p. 7: $\operatorname{card}(X) \le \operatorname{card}(\mathbb{N})$) but *countably infinite* from Lee (p. 600: a bijection with $\mathbb{N}$), whereas Folland defines countably infinite as "countable but not finite" (p. 7). With the unit's pair of definitions, "Should $X$ be countably infinite, $\operatorname{card}(X) = \operatorname{card}(\mathbb{N})$" is a restatement of the definition of countably infinite, not a proposition; what Folland's Prop 0.10(c) actually asserts is that an *infinite countable* set admits a bijection onto $\mathbb{N}$. That assertion appears in the unit only inside the definition block (line 104) as "So every finite set is countable, and a countable set is either finite or countably infinite", where the "So" is unjustified: the first half follows from the definitions, the second half is exactly Prop 0.10(c) and does not. The item's second sentence ("an infinite $S \subseteq \mathbb{N}$ admits a bijection onto $\mathbb{N}$") does carry real content, which is why this is minor rather than blocking. Fix: state item 3 as "If $X$ is countable and infinite, then $\operatorname{card}(X) = \operatorname{card}(\mathbb{N})$ (so a countable set is either finite or in bijection with $\mathbb{N}$)", and in the definition block either drop the "So ... either finite or countably infinite" clause or forward-reference the statement for it.
2. [minor] statement "Cantor's theorem" (lines 115, 124): the block says "Let $X$ be any set" and concludes $\operatorname{card}(X) < \operatorname{card}(\mathcal{P}(X))$ "for every set $X$", but the preceding definition block defines the comparison relations only "For nonempty sets $X$ and $Y$" and extends to $\emptyset$ only $\operatorname{card}(\emptyset) \le \operatorname{card}(X)$ and $\operatorname{card}(X) \ge \operatorname{card}(\emptyset)$ - the strict relation $<$ is given no meaning when $X = \emptyset$. The conclusion is true for $\emptyset$ on any reasonable reading (the empty map is an injection $\emptyset \to \{\emptyset\}$ and there is no bijection), but the unit's own definitions do not license writing it. Folland has the same gap but protects himself: on p. 6 he says that for the rest of §0.3 all sets are assumed nonempty. Fix: say "nonempty set" in this block, or extend $<$ and $>$ to $\emptyset$ where the relations are defined.

The frontmatter `pages: "2-7"` covers p. 7, so this is a block-locator omission, not an uncited borrowing. Fix: add p. 7 (Example 1.2.5) to the block `src`.

- Counterexample search. Inverse-image identities (lines 80-88): brute-forced every map $f : \{0,1,2\} \to \{0,1\}$ against all $2^3 \times 2^3$ pairs of subsets plus 20000 random instances on larger finite sets - $f^{-1}$ commutes with union, intersection and relative complement, and the direct image with union, in every case, with no violation. The negative claim at line 91 (image commutes with neither intersections nor complements) is witnessed by the unit's own $x^2$ example. The three sharp forms in the remark (lines 146-148) were verified as *iff* statements, not just implications: over every map $\{0,1,2\} \to \{0,1\}$, "$D = f^{-1}(f(D))$ for all $D$" held exactly for the injective maps, "$f(f^{-1}(E)) = E$ for all $E$" exactly for the surjective maps, and "$f(\bigcap D_\alpha) = \bigcap f(D_\alpha)$ for all families" exactly for the injective maps. Comparison relations: checked the degenerate cases $X = \emptyset$ (finding 2), $X$ a singleton, and $X$ finite against the definitions; Schröder-Bernstein and statement item 2 both carry the "nonempty" hypothesis they need (an injection $X \to Y$ gives a surjection $Y \to X$ only if $X \neq \emptyset$, which is Folland's own proof on p. 7). Cantor's theorem as the unit states it (the set $Y = \{x : x \notin g(x)\}$ is outside the range of any $g$) survives $X = \emptyset$, $g$ constant, and $g$ injective. Countability list: item 2's hypothesis on the index set is necessary (the unit's own $\mathbb{R} = \bigcup_{x} \{x\}$), item 5's identification $\operatorname{card}(\mathcal{P}(\mathbb{N})) = \mathfrak{c}$ is Folland Prop 0.12, item 6 is Folland Cor 0.13 verbatim and is also true directly (countable $X$ with $\operatorname{card}(X) > \mathfrak{c}$ would force $\operatorname{card}(X) = \mathfrak{c}$ by Schröder-Bernstein). The choice-dependence noted in the remark is right: Folland's proof of Prop 0.6 (p. 7) picks an element of $\prod_{x} g^{-1}(\{x\})$ and his proof of Prop 0.10(b) (p. 8) picks one surjection $f_\alpha$ per index.
