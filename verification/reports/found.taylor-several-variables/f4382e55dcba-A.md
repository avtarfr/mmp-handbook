## Findings
1. [blocking] statement[Classification of a critical point by the Hessian], part 5: the non-decidability claim is false for half the cases it covers, and it contradicts part 4 of the same statement. Part 5 applies to every $H$ that is semidefinite and singular, which includes the negative semidefinite singular ones, and then asserts "there are functions with this same $\nabla f(a)$ and $H_f(a)$ for which $a$ is a strict local minimum". Take $H = \operatorname{diag}(-2,0)$ (negative semidefinite, singular, zero eigenvalue with the one non-zero eigenvalue negative, so part 5's "equivalently" clause is satisfied). No function with $H_f(a) = H$ can have even a non-strict local minimum at $a$: part 4 of this very statement says a local minimum forces $H$ positive semidefinite, and directly $f(a+te_1) = f(a) - t^2 + o(t^2) < f(a)$ for all small $t \neq 0$. Fix: state the dichotomy with the sign that $H$ permits, e.g. "if $H$ is positive semidefinite and singular there are functions with this gradient and Hessian for which $a$ is a strict local minimum and others for which it is not a local extremum; if $H$ is negative semidefinite and singular, the same with maximum in place of minimum; if $H = 0$, all three outcomes occur." Note that $H = 0$ is both positive and negative semidefinite, so the $H = 0$ case is the only one where "strict local minimum" and "strict local maximum" are both attainable.
