## Findings
1. [minor] definition (line 49): the one-line proof that the Riemann sums converge bounds the
   modulus of a complex integral by the integral of the modulus — the inequality that is proved only
   later, in part 3 of the proof. The remark is explicitly optional ("Nothing below uses the
   Riemann-sum form"), so nothing is circular, but a forward pointer to part 3 would make the order
   honest.
2. [minor] definition (line 59): "A closed contour is traversed in the **positive** sense when the
   region it encloses lies to its left" — "the region it encloses" is defined only for a *simple*
   closed contour, which is how the same sentence is phrased in `complex.cauchy-theorem`. Fix:
   insert "simple".
3. [minor] proof, (a) $\Rightarrow$ (c) (line 128): $F(z)$ is defined by integrating along "any path
   $\sigma$ in $\Omega$" from $z_0$, and the last piece is then taken horizontal or vertical. This
   needs that the component of the open set $\Omega$ containing $z_0$ is itself open and that every
   point of it is reachable from $z_0$ by an axis-parallel polygonal path in $\Omega$. Ahlfors does
   the same silently (p. 106, "join it to $(x,y)$ by a polygon $\gamma$ ... whose sides are parallel
   to the coordinate axes"), so this is not infidelity; half a sentence would close it.
