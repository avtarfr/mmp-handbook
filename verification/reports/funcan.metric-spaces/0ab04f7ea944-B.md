## Findings
1. [minor] :::statement[The basic facts], part 8 (line 91): "$\mathbb{Q}$ ... is incomplete, as is any open interval of $\mathbb{R}$". Read literally this is contradicted by part 7 of the same block, since $\mathbb{R} = (-\infty,\infty)$ is an open interval of $\mathbb{R}$ and part 7 declares it complete (the empty interval is a second degenerate exception). No reader will be misled, but the two parts of one statement block should not conflict. Fix: "as is any bounded open interval $(a,b)$ with $a<b$".
2. [minor] :::proof[Part 7 for $C[a,b]$, and part 8], step 2 of the $d_1$ argument (line 141): "the triangle inequality in $d_1$ — which is an honest metric on the piecewise-continuous functions". On the piecewise-continuous functions $d_1$ is a *pseudo*metric, not a metric: $\operatorname{sgn}$ and the function that agrees with it except at $t=0$ are distinct and at $d_1$-distance $0$, so (M2) fails. The unit's own remark bullet on (M2) (line 147) says exactly this about integral distances, so the aside contradicts the remark. The argument itself needs only the triangle inequality, which does hold. Fix: "which satisfies the triangle inequality on the piecewise-continuous functions (it is only a pseudometric there, which this argument does not need)".
