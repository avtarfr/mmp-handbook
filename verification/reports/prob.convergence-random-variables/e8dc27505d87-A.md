2. [minor] remark, counterexample 3 (line 192): from $\sum_n \mathbb{P}(X_n=1) = \infty$ and independence the second Borel-Cantelli lemma gives $X_n = 1$ infinitely often almost surely, and that is enough for the stated headline (no almost sure convergence). The stronger conclusion actually drawn, "the sequence therefore converges almost nowhere", needs the companion application of the same lemma to $\{X_n = 0\}$, since $\sum_n (1-1/n) = \infty$ as well; without it the argument rules out only the limit $0$. Grimmett and Stirzaker's (7.2.11), p. 357, claims only that the sequence does not converge almost surely. Fix: add the one clause, or weaken the conclusion to match the source.
3. [minor] proof, step 7 (line 151): $\mathbb{P}(|X| \le k+\epsilon) = 1$ for every $\epsilon > 0$ is established, but the passage from that to "$|X| \le k$ almost surely" needs the final $\epsilon \downarrow 0$ step (continuity of $\mathbb{P}$ along the decreasing events $\{|X| \le k + 1/m\}$). One clause, as in Grimmett and Stirzaker's Theorem (7.2.4b), p. 357.
4. [minor] example (line 227): "$\liminf_{n\to\infty} X_n(\omega) = 0 \ (\text{for } k \ge 2)$" attaches a condition on $k$ to a statement in which $k$ does not occur; the intended meaning is that every block after the first contributes at least one zero. Fix: state it as "each block with $k \ge 2$ contributes at least one index with $X_n(\omega)=0$, so $\liminf_n X_n(\omega) = 0$".
