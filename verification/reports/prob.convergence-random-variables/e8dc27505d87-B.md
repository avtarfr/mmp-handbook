1. [minor] :::remark, counterexample 3 (line 192): "by the *second* Borel-Cantelli lemma $X_n = 1$ for infinitely many $n$, almost surely; the sequence therefore converges almost nowhere." The conclusion is true but does not follow from what is stated: $X_n = 1$ i.o. only rules out convergence to $0$. Non-convergence also needs $X_n = 0$ i.o., which is a second application of the same lemma to the complements ($\sum_n (1 - 1/n) = \infty$, still independent). Fix: add the one clause applying the lemma to $\{X_n = 0\}$ as well, so that $\liminf = 0 < 1 = \limsup$ almost surely.
