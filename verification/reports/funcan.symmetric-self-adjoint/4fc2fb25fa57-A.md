## Findings
1. [minor] definition, first block (line 39) and proof "The chain and the reality" (line 130): the third characterisation — $T$ densely defined is symmetric iff $(T\varphi,\varphi)$ is real on $D(T)$ — is located at "kreyszig-1978:§10.2, p. 534". In Kreyszig it is Problem 3 of §10.2, printed on p. 535, which lies outside the `pages: "533-534, ..."` range in the front matter. The attribution itself is right (Kreyszig does state it, as an exercise, not a numbered theorem). Fix: change the locator to "§10.2, Problem 3, p. 535", extend the `pages` range, and say it is set as a problem there.
2. [minor] note (line 108) and front matter (line 28): Arfken's Example 5.4.1 begins on p. 284 but its integration by parts and its conclusion ("Thus both $x$ and $p$ are self-adjoint") are on p. 285, which is outside the cited `pages: "283-284"`. The description of what the example does is accurate. Fix: cite pp. 283–285.
3. [minor] definition, first block (line 41): "A subspace $D \subseteq D(T)$ with $\overline{T|_{D}} = T$ is a **core**." Reed and Simon (p. 256) and `funcan.unbounded-operators` both define a core only for a *closed* $T$; for a non-closed $T$ the equation $\overline{T|_D}=T$ cannot hold. The qualifier has been dropped here, so the two units state the same definition differently. Fix: restore "If $T$ is closed, ...".
4. [minor] application (line 334): "The Hamiltonian $-\tfrac{\hbar^{2}}{2m}\,d^{2}/dx^{2}$ on the same domain *is* self-adjoint." It is not the same domain: $p_0$ has domain $\{u\in AC[0,1] : u'\in L^2,\ u(0)=u(1)=0\}$, while the Dirichlet Laplacian's domain is $\{u : u,u' \in AC,\ u''\in L^{2},\ u(0)=u(1)=0\}$. The sentence self-corrects at its end ("on the same boundary conditions"), so this is wording only. Fix: "with the same boundary conditions".
5. [minor] idea (line 124): "self-adjoint extensions of $T$ correspond to unitary extensions of $U_{T}$" states a bijection, whereas only one direction (self-adjoint extension $\Rightarrow$ unitary extension) is proved, and the statement block explicitly says the converse is von Neumann's theorem, not held in this library. Fix: "every self-adjoint extension of $T$ gives a unitary extension of $U_{T}$".
