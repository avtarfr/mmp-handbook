2. [blocking] `application`, "Transport with weak diffusion" (line 245): the hypothesis $p < 1$ is dropped. The unit says Stakgold & Holst's Remark 1 on $-\Delta U = -\lambda U^{p}$ gives "once $\lambda$ is large the set on which $U$ vanishes covers all of the domain apart from a thin collar". The dead core exists only for $p < 1$ — the book states this explicitly when it introduces (9.4.55) on p. 612 ("for $p<1$ and $\lambda$ sufficiently large, there will exist an interior subregion (known as a dead core)"), and on the same page gives the counterexample $p = 1$, $\Omega = \{|x|<a\}$, whose solution $U = \cosh(\sqrt\lambda x)/\cosh(\sqrt\lambda a)$ is strictly positive for every $\lambda$, so no dead core and no collar. As written the attributed statement is false for $p \ge 1$. The frontmatter `loc` (line 19) carries the same omission. Fix: say "for $p<1$" in both the body sentence and the `loc`.
3. [minor] `application` (line 249): $P := ah/(2\epsilon)$ is called "the cell Péclet number". The usual cell Péclet (cell Reynolds) number is $ah/\epsilon$, with the oscillation threshold at $2$; the unit's $P$ is half of it, with threshold $1$. The mesh condition $h > 2\epsilon/a$ that follows is correct either way. Fix: either call $P$ "half the cell Péclet number" or define $\mathrm{Pe} = ah/\epsilon$ and state the threshold as $\mathrm{Pe} > 2$.
