Fix: "for a real matrix $Q$, with $\dagger$ replaced by $\mathsf T$, $\mathbb{C}^n$ by $\mathbb{R}^n$ and the inner product by $x^{\mathsf T}y$".
3. [minor] proof, "The rows" (line 73): "for a non-square matrix $U^\dagger U = I$ and $U U^\dagger = I$ are not equivalent, and only one of them can hold". Neither need hold for a non-square matrix (the zero matrix satisfies neither), so the true claim is "at most one of them can hold". The proof of this is also left implicit; it is the rank count $n = \operatorname{rank}(U^\dagger U) \le \min(m,n)$ against $m = \operatorname{rank}(UU^\dagger)$. Fix: "at most one of them can hold", with the rank reason in a clause.
4. [minor] remark "Conventions and traps", "Real versus complex diagonalization" (line 180): "A unitary matrix is normal, hence unitarily diagonalizable over $\mathbb{C}$" uses a result that lives in :ref{to=linalg.normal-matrices}, which is not in `prereqs` and cannot be, since that unit lists this one as a prerequisite. The claim is only used to draw a contrast, not in any proof, and the note at line 166 already points forward in the same way. Fix: say explicitly that this is a forward reference (e.g. "as :ref[normal matrices]{to=linalg.normal-matrices} shows"), so the absence from `prereqs` is visibly deliberate rather than an omission.
