## Findings
1. [blocking] application (line 232): the sawtooth is described wrongly, and the description contradicts the rest of the same sentence. With $u_k$ linear on each $\bigl(\tfrac{j-1}{2k},\tfrac{j}{2k}\bigr)$, slope $+1$ for $j$ odd and $-1$ for $j$ even, and $u_k(0)=0$, one gets $u_k(j/(2k)) = 1/(2k)$ for $j$ odd and $0$ for $j$ even. So "it vanishes at every endpoint $j/(2k)$" is false; and taken together with "linear on each of the $2k$ intervals" it forces $u_k \equiv 0$, which contradicts the very next clause $\lVert u_k\rVert_\infty = 1/(2k)$ and the claim $E(u_k) = 0$. Everything the paragraph actually needs is true (the zigzag has $u_k(0)=u_k(1)=0$, $\lVert u_k\rVert_\infty = 1/(2k)$, $u_k' = \pm1$ a.e., $E(u_k)=0$, $E(0)=1$); only the stated reason is wrong. Fix: "it vanishes at $x = j/(2k)$ for every even $j$ — in particular $u_k(0) = u_k(1) = 0$, since $j = 2k$ is even — and rises to $1/(2k)$ at the odd ones, so $\lVert u_k\rVert_\infty = 1/(2k) \to 0$".

Fix: add both ids to `prereqs`.

[minor] proof (line 98): the equality $\int_{A_n}\varphi\,d\mu = \sum_{j=1}^N a_j\,\mu(E_j\cap A_n)$ is written without saying that $\varphi = \sum_j a_j\mathbf{1}_{E_j}$ is in standard representation (the $E_j$ disjoint), and without a justification. It is claim 3 of :ref[]{to=measure.lebesgue-integral} ("each simple function induces a measure"), which is where Folland points as well (Prop. 2.13d). Fix: say "in standard representation" in step 2 and cite claim 3 at the equality.

Fix: add the half-sentence "the terms being non-negative, so no $\infty-\infty$ arises".

[source] remark (line 149) and frontmatter (lines 23-24): Stakgold and Holst's Thm 0.7.3 (p. 47) states Fatou's lemma for an arbitrary sequence of measurable functions, with no non-negativity and no integrable lower bound, and as printed it is false — the unit's own $-n\mathbf{1}_{(0,1/n)}$ is a counterexample. The unit reports this faithfully, states the non-negative Folland/Evans version, and flags the difference, so this is not a fault of ours.
