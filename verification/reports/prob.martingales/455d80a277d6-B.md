1. [blocking] application (line 235): the displayed identity
   $$\mathbb{P}\Bigl(\sup_{n\ge0} Y_n \ge a\Bigr) \;=\; \mathbb{P}(T<\infty)$$
   is false, and with it the derivation of the maximal bound as written. The two events differ whenever the supremum is approached but never attained, and that has positive probability for some non-negative martingales. Counterexample (constructed and checked numerically, below): let $c_n = 2-2^{-n}$, so $c_0=1$; let $Y_n = c_n$ while "alive" and $Y_n = 0$ once "dead", where from the alive state the process survives with probability $r_n = c_n/c_{n+1}$ and otherwise jumps to the absorbing $0$. Then $\mathbb{E}(Y_{n+1}\mid\mathcal{F}_n) = r_nc_{n+1} = c_n = Y_n$ on the alive event and $0=Y_n$ on the dead one, so $(Y,F)$ is a non-negative martingale with $\mathbb{E}(Y_0)=1$. Take $a=2$. Survival for ever has probability $\lim_n c_0/c_n = 1/2$, and on that event $Y_n = 2-2^{-n} < 2$ for every $n$ with $\sup_n Y_n = 2$. Hence $T = \min\{n : Y_n\ge2\} = \infty$ almost surely, so $\mathbb{P}(T<\infty) = 0$ while $\mathbb{P}(\sup_n Y_n \ge 2) = 1/2$. The two sides of the unit's identity are $1/2$ and $0$.
   What the unit proves is $\mathbb{P}(T\le n)\le 1/a$ for every $n$, hence $\mathbb{P}(T<\infty)\le1/a$ - that part is correct, and it is the only thing the rest of the block uses ("the probability of ever rejecting a true null"). The *stated* conclusion about $\sup_{n\ge0}Y_n$ happens still to be true (Ville's inequality; my counterexample attains $\mathbb{P}(\sup \ge a) = 1/a$ exactly, so the bound is tight) but does not follow from the argument given, because the required inclusion $\{\sup_n Y_n \ge a\}\subseteq\{T<\infty\}$ is the one that fails. Fix: either state the conclusion as $\mathbb{P}(Y_n \ge a \text{ for some } n) = \mathbb{P}(T<\infty) \le 1/a$, which is exactly what the proof gives and exactly what the testing application needs; or keep the $\sup$ form and add the limiting step - run the same argument with $T_b = \min\{n : Y_n \ge b\}$ for $b<a$, note $\{\sup_n Y_n \ge a\}\subseteq\{T_b<\infty\}$, so $\mathbb{P}(\sup_n Y_n\ge a)\le 1/b$ for all $b<a$, and let $b\uparrow a$.
