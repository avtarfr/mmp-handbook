1. [minor] frontmatter `prereqs` (line 7): the unit relies on :ref[]{to=group.group-actions} in both the `idea` and the `proof` of the disjoint-cycle decomposition ("the orbits partition $A$ ... which is part 1 of the orbit–stabilizer theorem"), but `group.group-actions` is not listed among the prerequisites. The style guide requires every prerequisite relied on to be named. `group.group-actions` precedes this unit in `content/map.yaml`, so adding it introduces no ordering warning. Fix: add `group.group-actions` to `prereqs`.
2. [minor] definition, "Cycle type" paragraph (line 39): "We list cycle types in non-decreasing order, as Dummit and Foote do; Hassani writes partitions in non-increasing order instead. The two record the same data." The ordering claim about each book is accurate (DF p. 126 require $n_1 \le n_2 \le \dots \le n_r$; Hassani Eq. (23.4) has $\lambda_1 \ge \lambda_2 \ge \dots \ge 0$), but Hassani's $\lambda_j \equiv \sum_{k\ge j}\nu_k$ is the *conjugate* partition, not the reversed list of cycle lengths: the cycle type $1,2,2$ in $S_5$ is DF's $(1,2,2)$ but Hassani's $(3,2)$. So "the two record the same data" is true only in the weak sense that both are partitions of $n$ in bijection with cycle structures, not that one is the other read backwards. Fix: either say Hassani labels a cycle structure by the conjugate partition $\lambda_j = \sum_{k\ge j}\nu_k$, written non-increasingly, or restrict the sentence to DF's convention and drop the Hassani comparison.
3. [minor] method "Working with a permutation" (line 140): the block is labelled `provenance=original`, but step 1 is the Cycle Decomposition Algorithm of :cite{work=dummit-foote-2004 loc="§1.3, p. 30"} ("to start a new cycle pick the smallest element ... which has not yet appeared in a previous cycle"), step 6 is DF p. 31 ("the cycle decomposition of $\sigma^{-1}$ is obtained by writing the numbers in each cycle in reverse order"), and step 3 is RHB §28.4 p. 1058. The unit's own frontmatter already names "the decomposition algorithm" among what it takes from DF. The seven-step recipe as a whole is our synthesis and no wording is close to either book, so this is a labelling point rather than a copyright one. Fix: relabel the block `adapted` with `src="dummit-foote-2004:§1.3, pp. 30-31; rhb-2006:§28.4, p. 1058"`.
4. [minor] remark, final paragraph (line 133): "Parity is not the parity of the order. $(1\,2)$ and $(1\,2)(3\,4)$ both have order 2, yet the first is odd and the second even." :cite{work=dummit-foote-2004 loc="§3.5, p. 110"} closes its discussion with the same caution and the same two permutations. The example is the smallest one possible, so this is not a paraphrase problem, but the paragraph sits in a block labelled `provenance=original`. Fix: add `src="dummit-foote-2004:§3.5, p. 110"` to the remark, or attribute that one caution inline with `:cite`.
