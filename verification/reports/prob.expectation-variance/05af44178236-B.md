## Findings
1. [source] grimmett-stirzaker-2020, Lemma (3.6.8), p. 69. The book states the equality case as "|rho(X,Y)| <= 1 with equality if and only if P(aX + bY = c) = 1 for some a, b, c in R", with no requirement that a and b be not both zero; read literally the condition is met by a = b = c = 0 for every pair, so the "only if" direction is vacuous. The book's own Theorem (3.6.9), immediately below, does carry "at least one of which is non-zero". Our statement rule 7 (line 115) supplies the missing qualifier, which is the correct reading. Recorded with `node tools/discrepancy.mjs add prob.expectation-variance grimmett-stirzaker-2020 "Lemma (3.6.8), p. 69" ...`. Not a defect in our text.
2. [minor] proof, rule 1, continuous case (line 134): "the corresponding statement for g >= 0 follows from rule 9 applied to g(X)". Rule 9 as stated and proved in this unit is for a non-negative X *with a density* (the proof writes 1 - F(x) = int_x^inf f(y) dy), and g(X) need not have one — g(X) can be discrete, as when g is an indicator. The identity E(Z) = int_0^inf P(Z > z) dz is true for every non-negative Z, so nothing downstream is wrong, but as written the argument leans on a case of rule 9 that this unit has not established. Fix: state rule 9 for an arbitrary non-negative variable via the distribution function (G&S Lemma (4.3.4) is in that form), or prove the continuous change-of-variable formula directly from G&S Theorem (4.3.3), which is already cited for the block.
3. [minor] example (line 265): "the positive coupling inflates the variance of the total by 35%". The exact figure is 1.1275/0.8375 = 1.34627, i.e. 34.6%. Rounding to 35% is defensible but every other number in this example is given to six places. Fix: write 34.6%.
