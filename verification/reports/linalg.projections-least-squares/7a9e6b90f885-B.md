## Findings
1. [source] remark, bullet "Only the parallelogram law makes the nearest point exist and be unique" (line 83): the Banach-space counterexample is wrong, but it is wrong in the source and the unit reports it faithfully, so under `docs/contributing/source-authority.md` this does not fail the unit. The unit says, after `stakgold-holst-2011` Remark 2 on p. 267, that in `C[0,1]` with the supremum norm and `M` the continuous functions vanishing at `0`, the function `u = 1` "has no closest element in M". The nearest point does exist. Since every `f` in `M` has `f(0) = 0`, `||u - f||_inf >= |1 - f(0)| = 1`, so the distance is at least 1; and `f = 0` is in `M` with `||1 - 0||_inf = 1`, as are `f(x) = x` and `f(x) = 2x`. I computed all three on a 200001-point grid of `[0,1]` and got `||1 - f||_inf = 1.0` in each case, so the infimum is 1 and is attained - by infinitely many elements. What this example actually shows is that the nearest point need not be *unique* in a Banach space, not that it need not exist. (Existence genuinely can fail in a Banach space, so the bullet's heading is defensible; only the example is not.) Recorded with `node tools/discrepancy.mjs add linalg.projections-least-squares stakgold-holst-2011 "section 4.5, Remarks on the Proof, Remark 2, p. 267" ...`. If the drafters want a bullet that stands on its own, the honest version is: in a Banach space the nearest point may fail to be unique, and this `C[0,1]` example shows it; attribute the non-existence claim to Stakgold and Holst's remark rather than asserting it.
2. [minor] remark, bullet "Convexity, not linearity" (line 84): two imprecisions. (a) "Kreyszig's Theorem 3.3-1 assumes only that `M` is convex and complete" drops the nonemptiness: the theorem reads "let X be an inner product space and `M != 0` a convex subset which is complete" (p. 144). For `M` empty there is no minimiser at all. (b) "For a merely convex set the nearest point still exists and is unique" needs completeness (or closedness) carried over from the first clause; as a free-standing sentence about convex sets it is false - the open unit ball in `R^n` is convex with no nearest point to an exterior vector. Fix: "Kreyszig's Theorem 3.3-1 assumes only that `M` is nonempty, convex and complete ... For a nonempty complete convex set the nearest point still exists and is unique, but the residual satisfies only a variational inequality."
3. [minor] definition (line 39) and statement "Least squares", part 1 (line 61): the least-squares definition minimises `||Ax - b||` over `F^n` without saying which norm on `F^m` is meant, and part 1 applies the projection statement to `im A` without naming the inner product. The companion unit :ref[Orthonormal bases and Gram-Schmidt]{to=linalg.gram-schmidt} is explicit about this ("give `F^m` its standard inner product"), so the omission is inconsistent within the chapter rather than ambiguous in practice. Fix: add "with `F^m` carrying its standard inner product `(u,v) = sum_i u_i conj(v_i)`" to the definition block.
4. [minor] statement "Projection onto a finite-dimensional subspace", part 5 (line 55): the converse is stated with `dim V < infinity`, which is stronger than needed - a self-adjoint idempotent on any inner product space is the orthogonal projection onto its image, since `V = im P + ker P` and `ker P = (im P)^perp` follow from `P^2 = P = P*` alone, and Kreyszig's Thm 9.5-1(b) (p. 481) states it for an arbitrary Hilbert space. Not wrong, and the phase file's instruction is to state the weaker hypothesis one can justify. Fix: drop `dim V < infinity` from the converse, or note in the remark why it is kept.
