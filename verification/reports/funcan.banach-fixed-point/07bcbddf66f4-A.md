## Findings
1. [minor] statement, parts 4 and 5 (lines 76 and 78): part 1 is careful to require $X$ *nonempty* and the proof flags the point ("Fix $x_0 \in X$ (possible because $X \ne \varnothing$)"), but parts 4 and 5 ask only that $S$ be closed. For $S=\varnothing$ the empty map is vacuously a contraction and has no fixed point, so as written those two parts are false in that degenerate case, and part 4's proof — "apply part 1 to $(S,d)$" — cannot be run. Kreyszig and Stakgold and Holst both state their closed-set versions without the word (Stakgold and Holst p. 246), so this is not an infidelity, only an inconsistency with the unit's own part 1. Fix: write "a *nonempty closed* set" in parts 4 and 5.
2. [minor] remark (line 164): "A weak contraction on a *compact* set does have a fixed point, since $x\mapsto d(x,Tx)$ is then continuous on a compact set and attains its minimum, which must be $0$." The last clause is the whole content of the argument and is not justified; the reason is that if the minimiser $x_0$ had $Tx_0\ne x_0$ then $d(Tx_0,T^2x_0)<d(x_0,Tx_0)$, contradicting minimality. Fix: add that half-sentence (and, for completeness, that $x\mapsto d(x,Tx)$ is continuous because a weak contraction is non-expansive, hence continuous).
3. [minor] remark (line 166): "A bound computed with an overestimate $\alpha' > \alpha$ is still valid (both sides increase)". Only the right-hand side moves — $d(x_m,x^\ast)$ is a fixed number — and what makes the remark true is that $\alpha\mapsto\alpha^m/(1-\alpha)$ and $\alpha\mapsto\alpha/(1-\alpha)$ are increasing on $[0,1)$ while $T$ is still a contraction with constant $\alpha'$. Fix: "(the right-hand side is increasing in $\alpha$)".
4. [minor] definition (line 33): "The smallest such $\alpha$ is the **contraction constant**." The infimum is attained, since $\sup_{x\ne y} d(Tx,Ty)/d(x,y)$ is itself a Lipschitz constant, but the unit asserts the minimum without saying why; a four-word parenthesis ("the supremum of the ratios") would settle it. Not wrong as stated.
