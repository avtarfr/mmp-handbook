## Findings

[blocking] definition[Eigenvalue, eigenvector, eigenspace] (line 31): "Eigenvectors are determined only up to a non-zero scalar multiple" is false whenever $g(\lambda)\ge 2$, and the same block defines exactly that case six lines later ("**degenerate** when $g(\lambda)\ge2$", line 37). The unit's own first example contradicts it: $E_3$ there is a plane with basis $(-1,1,0)$ and $(1,0,1)$, which are not multiples of one another. This is not what the cited source says either — RHB p. 273 states only the true direction, that any scalar multiple $\mu x$ of an eigenvector is again an eigenvector with the same eigenvalue, and draws the normalisation convention from that. Fix: "A non-zero scalar multiple of an eigenvector for $\lambda$ is again an eigenvector for $\lambda$, so an eigenvector is fixed only after a normalisation is chosen; one often takes $x^\dagger x = 1$."
