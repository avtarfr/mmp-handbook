## Findings
1. [minor] example (line 226): the four quoted terms are misrounded in their last digits. The terms $[\omega_{n}^{2}(\omega_{n}^{2}-1)]^{-1}$ are $0.2761922$, $0.00212347$, $0.000267140$, $0.0000689819$, that is $0.27619$, $0.0021235$, $0.00026714$, $0.00006898$, against the printed $0.27620$, $0.0021238$, $0.00026716$, $0.00006890$. The eleven-term total $0.5574026$, the series value $1.5574026$ and the comparison with $\tan1=1.5574077$ are all right, so only the four printed terms need correcting.
2. [minor] proof, part 1 (line 110): the interchange of the order of integration is justified "(Cauchy–Schwarz on the square, using $K\in L^{2}$ and $u\overline{w}\in L^{1}$)". What Cauchy–Schwarz on the square needs is that $(x,t)\mapsto u(t)\overline{w(x)}$ lie in $L^{2}$ of the square, with norm $\lVert u\rVert\lVert w\rVert$; the $L^{1}$ statement is not the one used. Fix: name $L^{2}$.
3. [minor] statement, part 3: "convergent in mean square in either variable for each fixed value of the other" holds for almost every fixed value, since $K_{m}$ is only defined a.e. for an $L^{2}$ kernel. Stakgold and Holst phrase it the same way (p. 377), so this is presentation, not a defect.
