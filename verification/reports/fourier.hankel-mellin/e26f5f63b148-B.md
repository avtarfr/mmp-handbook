## Findings

1. [source] note "Where the sources differ" (line 75) / rhb-2006 §13.3, pair (ii), p. 459: Riley, Hobson and Bence print the Mellin inversion with fixed limits $-i\infty$ to $i\infty$ and never mention a strip of convergence. That prescription fails whenever the strip omits $\operatorname{Re}z = 0$ — the unit's own $f(t) = 1/(1+t)$, strip $0<\operatorname{Re}z<1$, is the counterexample, since $\pi/\sin\pi z$ has a pole at $z=0$. The unit reports the source faithfully, states which convention it follows (Arfken (21.20), Hassani Problem 16.1) and explains the difference, so this is a defect in the source, not in our text. Recorded with `tools/discrepancy.mjs add fourier.hankel-mellin rhb-2006 "§13.3, concluding remarks, transform pair (ii), p. 459"`. Not blocking.

2. [minor] remark "Where the hypotheses are used" (line 255, last-but-two bullet): "On the larger space $L^2((0,\infty), r\,dr)$ part 3 shows $\mathcal{H}_0$ is an isometry". Part 3 is proved only for profiles of Schwartz functions on $\mathbb{R}^2$; extending the isometry to all of $L^2((0,\infty),r\,dr)$ needs a density argument that is not given. Fix: write "part 3 and a density argument show" or "part 3 extends by density".

3. [minor] example "A Mellin pair" (line 325, step 2): the keyhole result imported from :ref[complex.branch-cut-integrals] is stated there for a real exponent, $\int_0^\infty x^{p-1}(x+a)^{-1}dx = \pi a^{p-1}/\sin p\pi$ with $0<p<1$, whereas it is used here for complex $z$ in the strip. The companion route given in the same sentence (:ref[spec.beta-function] part 6, which does state $B(p,1-p)=\pi/\sin\pi p$ for $0<\operatorname{Re}p<1$) already covers the complex case, so the claim is supported; a half-sentence saying the keyhole value extends to complex $z$ by analytic continuation, or putting the Beta route first, would remove the gap.

4. [minor] frontmatter, hassani-2013 `loc` (line 24): "the Mellin kernel being $x^y$". Hassani, p. 493, writes $K(x,y) = G(x^y)$ and adds that most of the time it is taken to be simply $x^y$. The body's use of this source (Example 16.0.1(e), the Hankel kernel $yJ_n(xy)$) is exact; only the frontmatter summary compresses. Fix: "the Mellin kernel being $G(x^y)$, usually $x^y$".
