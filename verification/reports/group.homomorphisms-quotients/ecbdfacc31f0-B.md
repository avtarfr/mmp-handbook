## Findings
1. [source] rhb-2006, §28.5, consequence (iii), p. 1060. Riley, Hobson and Bence conclude "the image of an element has the same order as the element", while their displayed argument establishes only $\Phi(X)^{m} = I'$ when $X^{m} = I$, that is, divisibility; equality fails for the example printed on the same page ($\Phi : x \mapsto e^{\mathrm{i}x}$ sends $\pi$, of infinite order, to $-1$, of order 2). The unit reports this accurately, states that it follows Dummit and Foote's divisibility form, and gives the counterexample — exactly the treatment a conflict between two sources requires. Recorded with `node tools/discrepancy.mjs add`. Not a failure.
2. [source] hassani-2013, §23.2, Example 23.2.17, p. 711. Hassani writes the determinant homomorphism as $\det : GL(\mathcal{V}) \to \mathbb{R}^{+}$; the codomain should be $\mathbb{R}\setminus\{0\}$ for a real space (and $\mathbb{C}\setminus\{0\}$ for a complex one), since $\operatorname{diag}(-1,1,\dots,1)$ has determinant $-1$. The conclusion Hassani draws — $SL(\mathcal{V}) \trianglelefteq GL(\mathcal{V})$ as a kernel — is unaffected, and the unit uses the correct codomain. Recorded with `node tools/discrepancy.mjs add`. Not a failure.
3. [minor] example[Two quotients that physics uses constantly] (line 277): the clause "as :cite[Hassani]{work=hassani-2013 loc=\"§23.2, Example 23.2.17, p. 711\"} observes" is attached to a sentence whose main assertion is $GL(n,\mathbb{R})/SL(n,\mathbb{R}) \cong \mathbb{R}\setminus\{0\}$. Hassani's Example 23.2.17 asserts only that $SL(\mathcal{V})$ is normal in $GL(\mathcal{V})$, being $\ker \det$; the quotient isomorphism is our own application of the first isomorphism theorem, and Hassani's codomain differs (finding 2). The block is `provenance=original`, so nothing is mislabelled, but the cite over-reaches by one clause. Fix: move the cite onto the normality sentence ("So $SL(n,\mathbb{R})$ is normal in $GL(n,\mathbb{R})$ without any conjugation being computed (:cite[Hassani]{...}), and ...").
4. [minor] application, "Conserved quantities and selection rules" (line 287): "Parity is the homomorphism from a symmetry group onto $\{\pm 1\}$ whose kernel is the subgroup of orientation-preserving operations — a subgroup of index $2$, hence normal with no work." The index is $2$ only when the group actually contains an orientation-reversing operation; for a chiral point group the map is trivial, the kernel is the whole group and the index is $1$. Fix: "when the group contains an orientation-reversing operation, its orientation-preserving elements form a subgroup of index 2 ...".
