## Findings
1. [blocking] :::remark[Where the hypotheses are used], first bullet: "If $\mathbb{E}[e_b\varepsilon^{\mathsf T}] = C \ne 0$ ... then $A(K)$ acquires cross terms and the optimal gain becomes $(BH^{\mathsf T}+C)(HBH^{\mathsf T}+R+HC+C^{\mathsf T}H^{\mathsf T})^{-1}$." The signs are wrong: with the unit's own conventions ($e_b = x_b-x$, $y = Hx+\varepsilon$, $C = \mathbb{E}[e_b\varepsilon^{\mathsf T}]$, and therefore $d = \varepsilon - He_b$, as the definition block states) the correct gain is
   $$K_\ast^{C} = \bigl(BH^{\mathsf T}-C\bigr)\bigl(HBH^{\mathsf T}+R-HC-C^{\mathsf T}H^{\mathsf T}\bigr)^{-1}.$$
   Derivation: $x_a-x = (I-KH)e_b+K\varepsilon$, so $\mathbb{E}[(x_a-x)d^{\mathsf T}] = (I-KH)(C-BH^{\mathsf T}) + K(R-C^{\mathsf T}H^{\mathsf T})$, and setting this to zero gives the formula above; note also $\operatorname{Cov}[d] = HBH^{\mathsf T}+R-HC-C^{\mathsf T}H^{\mathsf T}$, so the unit's denominator is not even the innovation covariance. I confirmed this numerically: in the scalar case $B=2$, $R=0.5$, $C=0.6$ (correlation $0.6$), a $4\times10^6$-sample simulation puts the empirical minimiser of $\mathbb{E}[(x_a-x)^2]$ at $K = 1.077$ with error $0.49248$; the corrected formula gives $K = 1.076923$ (and sympy's exact minimisation of $(1-K)^2B+2K(1-K)C+K^2R$ gives $14/13 = 1.0769231$), while the unit's formula gives $K = 0.702703$ with error $0.67475$ -- $37\%$ worse, so this is not a rounding matter. The sign slip looks like it was carried over from the analogous remark in :ref[]{to=stats.kalman-filter}, where $\operatorname{cov}(x_k,y_k\mid Y_{k-1}) = P^f_kH_k^{\mathsf T}+C_k$ legitimately has a plus sign because there the noises enter the state and the observation with the same sign, whereas here $e_b$ enters the innovation with a minus. Fix: replace both $+$ by $-$, as displayed above.
2. [minor] Same bullet: "Using $K_\ast$ regardless gives an analysis that is still unbiased but whose true error exceeds the reported $A$." Unbiasedness is right (it needs only $\mathbb{E}[e_b] = \mathbb{E}[\varepsilon] = 0$). But the true error exceeds the reported one only when the omitted cross term $(I-K_\ast H)CK_\ast^{\mathsf T} + K_\ast C^{\mathsf T}(I-K_\ast H)^{\mathsf T}$ is positive -- for a negatively correlated $C$ the reported $A$ is pessimistic, not overconfident. The scenario the bullet names (a radiosonde used in both the background and the observations) does give positive correlation, so the warning is right there; it is the unqualified "exceeds" that over-reaches. Fix: "whose true error exceeds the reported $A$ whenever the correlation is positive, as it is when an observation has already been used to make the background".
3. [minor] :::example, step 2: the second numerator is printed as $-0.151289$; the exact value is $1.25\rho_{P2}-\rho_{12}\rho_{P1} = -0.15129028$, which rounds to $-0.151290$. A last-digit slip (the quoted weight $-0.135366$ is right). Fix: $-0.151290$.

Both are correct roundings of the exact $1.9490416$ -- the displayed sum is just rounded-then-added. Worth carrying one more digit in the intermediate terms so the line adds up as printed.
