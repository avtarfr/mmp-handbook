## Findings
1. [minor] statement (line 62): the Jensen clause ("if $\hat a$ is unbiased for $a$ and $\alpha$ is strictly convex ... then $\alpha(\hat a)$ is biased upwards") omits the non-degeneracy of $\hat a$ that the proof block (line 114) correctly supplies. As written it is false in the degenerate case $\hat a = a$ almost surely, where $\alpha(\hat a) = \alpha(a)$ is unbiased. Also "strictly convex ... and non-affine" is redundant, since a strictly convex function is never affine. Fix: carry "and $\hat a$ is non-degenerate" into the statement and drop "non-affine".
2. [minor] proof (line 112): the invariance argument via the induced likelihood $L^{*}(\alpha_0) = \sup\{L : \alpha(a) = \alpha_0\}$ is not Riley, Hobson and Bence's route - p. 1261 asserts $\hat{\alpha}(a) = \alpha(\hat a)$ by reading off the value of $\alpha$ at the maximum, with no treatment of non-injective $\alpha$. The block is labelled `adapted` to rhb-2006 §31.5.2, which over-attributes an argument that is ours. This is the harmless direction of a provenance label (nothing here is close to the source), but the honest labelling would be `original` for the invariance half with the statement cited, keeping the `adapted` src for the efficiency half, which does follow p. 1262 step for step.
3. [minor] example (line 157): the beacon-on-a-shore set-up is the classic "lighthouse problem" (Gull 1988, and the standard worked example in Sivia). No work in `bibliography/works.yaml` contains it, so there is nothing to cite, and the data, the three roots, the curvature and every derived number are our own; but a half-sentence acknowledging it as a classic would avoid any appearance of novelty.
4. [minor] example (line 213): "$1.163^{+0.196}_{-0.177}$: very nearly symmetric" understates the asymmetry a little - the two half-widths differ by about 10%, and both straddle the curvature value 0.1838. The conclusion drawn (the Gaussian approximation is doing no harm at $n=15$) is still fair.
5. [minor] application (line 237): the correlated-measurement covariance matrix is called $N$, while $n$ is the sample size in the same paragraph; Riley, Hobson and Bence call it $V$ (p. 1259). Nothing is ambiguous in the mathematics, but $V$ or $C$ would read better.
6. [minor] application (line 239): "$\ell = -\tfrac12\chi^{2}(a)$ exactly" holds up to the $a$-independent constant $-\tfrac12\sum_i\ln(2\pi\sigma_i^{2})$ and requires the $\sigma_i$ to be known. The conclusion (maximising $L$ is minimising $\chi^2$) is unaffected. Fix: "up to a constant free of $a$".
7. [minor] automated check: `node tools/check/index.mjs --record stats.maximum-likelihood` returns `ok` with one warn, "grimmett-stirzaker-2020 pp. 108, 373 never mention maximu/likeli; check the page numbers".
