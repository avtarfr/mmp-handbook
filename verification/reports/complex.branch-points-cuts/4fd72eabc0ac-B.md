## Findings

1. [blocking] example "Values and orders", item 2 (line ~140, `provenance=original`): "the finite cut $[-1,1]$ suffices; this is the cut taken for Legendre's second-kind functions $Q_n$, and for the plasma dispersion function." The Legendre half is right — $Q_n(z) = \tfrac12\int_{-1}^{1}P_n(t)(z-t)^{-1}dt$ is cut along $[-1,1]$. The plasma half is wrong. The plasma dispersion function means the Fried–Conte function $Z(\zeta) = i\sqrt{\pi}\,e^{-\zeta^2}\operatorname{erfc}(-i\zeta)$, which is **entire**: it has no branch point and no cut anywhere, and in particular none on $[-1,1]$. (What it has instead is a Landau prescription for which side of the real axis the defining integral is continued from, which is not a branch cut of $Z$.) This is an `original` block, so we own the claim and it must be right. Fix: delete "and for the plasma dispersion function"; or, if a plasma example is wanted, replace it with one that genuinely has a finite logarithmic cut (the response function of a bounded, e.g. box, velocity distribution) and cite a source for it, which `docs/contributing/source-authority.md` would then protect.

2. [minor] statement part 1 (line ~52) writes the principal branch with "$\operatorname{Arg} z \in (-\pi,\pi)$", while example "Values and orders" item 3 says "With the convention $\operatorname{Arg} z \in (-\pi,\pi]$" and the prerequisite unit `complex.elementary-functions` defines $\operatorname{Arg}$ with the half-open interval $(-\pi,\pi]$. Both are correct in their own place — on the cut plane $\mathbb{C}\setminus(-\infty,0]$ the argument does lie in the open interval — but as written the symbol $\operatorname{Arg}$ changes range inside the unit. Fix: in part 1 write "$\operatorname{Arg} z \in (-\pi,\pi)$ on the cut plane", or "$\operatorname{Arg}$ as in :ref{complex.elementary-functions}, whose values on $\mathbb{C}\setminus(-\infty,0]$ lie in $(-\pi,\pi)$".

3. [minor] statement part 1: "One cut from $0$ to $\infty$, along any curve, makes $\operatorname{Ln}$ single-valued." This needs the curve to be a simple arc; "any curve" as written admits self-intersecting curves that leave a loop around the origin in the complement. RHB p. 836 say "any curve starting at the origin $z=0$ and extending out to $\lvert z\rvert=\infty$", with the same tacit assumption. Fix: "along any simple arc".

4. [minor] example "A square root with two branch points and a finite cut" is labelled `original`, and its function, numbers and the whole of step 4 (the explicit branch $\sqrt{z-1}\sqrt{z-4}$ and the overlapping-ray argument) are genuinely ours. But steps 1–3 run exactly the route of RHB's worked example on pp. 836–837 for $(z^2+1)^{1/2}$ — list the branch points, tabulate the four loop cases, then observe that the loop around both is harmless so a finite cut will do. That route is credited in the `method` block immediately above, so this is not a mislabelling that misleads a reader, but adding `src="rhb-2006:§24.5, pp. 836–837"` to the example would be more honest.
