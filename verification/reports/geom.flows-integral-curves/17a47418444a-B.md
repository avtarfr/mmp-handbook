## Findings
1. [source] proof (line 87): the sketch of Lee's openness argument sets `t_0 = inf{t : (t, p_0) not in W}` and then concludes `t_0 > 0` from the ODE theorem's product neighbourhood of `(0, p_0)`. That neighbourhood only rules out small `|t|`; the infimum over *all* real `t` can be negative if `(t, p_0)` leaves `W` for some sufficiently negative `t`. The intended set is `{t > 0 : (t, p_0) not in W}`, non-empty because `tau > 0` was assumed. Lee (p. 213) writes exactly the same unrestricted infimum, so this is a faithful report of the source, not an error of ours; recorded with `tools/discrepancy.mjs` against lee-2013 "proof of Thm 9.12, p. 213". No change required, though adding "`t > 0`" would close the gap at no cost.

3. [minor] example (line 148): "`M_t = {}` for `|t| >= pi`: no single diffeomorphism `theta_t` moves the whole line for such `t`" is true but understates. For this field `M_t = (-infinity, cot t)` for `0 < t < pi`, so `theta_t` fails to move the whole line for *every* `t != 0`, not only for `|t| >= pi`; what is special about `|t| >= pi` is that `M_t` is empty outright.
