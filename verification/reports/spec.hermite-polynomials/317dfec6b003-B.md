## Findings

1. [blocking] application (line 337): the unit contradicts itself about the oscillator scale
   factor. One clause says "rescale $z=\hbar^{1/2}(km)^{-1/4}x$", i.e. $z=\alpha x$ and therefore
   $x=z/\alpha$; the next says "The eigenfunctions are $\psi_{n}(z)\propto
   \mathrm{e}^{-(\alpha z)^{2}/2}H_{n}(\alpha z)$ with $\alpha=\hbar^{1/2}/(km)^{1/4}$". Both cannot
   hold. With $\alpha$ as defined, $[\alpha]=\mathrm{kg}^{1/2}\,\mathrm{m}\,\mathrm{s}^{-1/2}/
   (\mathrm{kg}^{1/2}\mathrm{s}^{-1/2})=\mathrm{m}$, so $\alpha z$ is an area and $H_n(\alpha z)$ is
   not defined. I checked symbolically (sympy): with $\alpha$ as printed,
   $\mathrm{e}^{-(\alpha z)^{2}/2}H_{n}(\alpha z)$ is **not** an eigenfunction of
   $-\frac{\hbar^{2}}{2m}\partial_z^2+\frac{k}{2}z^{2}$ (the Rayleigh quotient retains a $z^{2}$
   term); with the argument $z/\alpha$ it is, with $E_n=(n+\tfrac12)\hbar\sqrt{k/m}$ for $n=0,1,2$,
   which is the energy the unit then quotes. So as written the displayed eigenfunction is unusable
   and inconsistent with the rescaling one clause earlier, with item 6, and with $E_n$.
   Fix: write $\psi_{n}(z)\propto\mathrm{e}^{-(z/\alpha)^{2}/2}H_{n}(z/\alpha)$ with
   $\alpha=\hbar^{1/2}/(km)^{1/4}$ (or keep $H_n(\alpha z)$ and define
   $\alpha=(km)^{1/4}/\hbar^{1/2}$), and add the half-sentence flagging that Arfken's eq. (18.19)
   prints the reciprocal, so that a reader comparing the two is not left puzzled. See finding 2.

2. [source] application (line 337), arfken-2013 §18.2, eq. (18.19), p. 879: the defect in finding 1
   is inherited from the source. Arfken's (18.19) prints
   $\psi_n(z)=N_n\mathrm{e}^{-(\alpha z)^2/2}H_n(\alpha z)$ with $\alpha=\hbar^{1/2}/(km)^{1/4}$,
   while his own substitution on p. 878 is $z=\hbar^{1/2}x/(km)^{1/4}$ and his own normalisation
   (18.20), $N_n=[\alpha/(2^{n}\sqrt{\pi}\,n!)]^{1/2}$, is correct only for the reciprocal
   $\alpha$. Recorded with `node tools/discrepancy.mjs add spec.hermite-polynomials arfken-2013
   "§18.2, eq. (18.19), p. 879" ...`. Per `docs/contributing/source-authority.md` this book error is not
   by itself a reason to fail; the blocking finding is that our text reproduces both halves of the
   inconsistency without flagging it, so the unit contradicts itself.

3. [minor] application (line 337): "$[H,A^{\dagger}]=A^{\dagger}$ moves one rung up" is right only
   for the dimensionless $H=N+\tfrac12$ used in item 6; for the dimensional $H$ of the preceding
   sentences it is $\hbar\omega A^{\dagger}$. One word ("in the units of item 6") would fix it.

4. [minor] statement item 3 (line 83): "For $n\ge0$" is correct for both recurrences only with the

   $n\ge1$, and $H_{0}'=0$", which is the same thing stated differently. Harmonising the two would
   save the reader a moment.

5. [minor] prerequisite order: `node tools/check/index.mjs` warns that `funcan.orthonormal-bases`
   and `measure.fubini-tonelli` come after this unit in `content/map.yaml`. Both are genuinely used
