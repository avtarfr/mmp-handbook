## Findings
1. [blocking] statement "Principal axes" (line 46), last sentence: "if some $\lambda_k = 0$ it is a cylinder: unbounded along $u_k$" is false. Take $n=2$, $A = \operatorname{diag}(0,-1)$: $\lambda_1 = 0$, yet $\{x : x^{\mathsf T}Ax = 1\} = \{x : -x_2^2 = 1\} = \varnothing$, which is neither a cylinder nor unbounded along $u_1$. The same failure occurs for $A = \operatorname{diag}(0,0)$ and for any $A$ with a zero eigenvalue and no positive one. The sentence also overlaps the preceding clause ambiguously: $A = \operatorname{diag}(1,-1,0)$ has mixed signs *and* a zero eigenvalue, so the text declares the level set both a hyperboloid and a cylinder. Fix: condition the whole geometric classification on $\lambda_n > 0$ (equivalently, on the level set being non-empty) and state the cases as: all $\lambda_k > 0$, ellipsoid; $\lambda_n > 0$ with some $\lambda_k < 0$, hyperboloid; $\lambda_n > 0$ with some $\lambda_k = 0$, unbounded along $u_k$; no $\lambda_k > 0$, empty.
2. [blocking] method "Analysing a quadratic form", step 5 (line 91): the same error, in the form the reader is told to apply. "if $\lambda_k \le 0$ it does not meet that line at all and the set is unbounded in the direction $u_k$" is false for $A = \operatorname{diag}(-1,-1)$, $c = 1$: the level set is empty, so it is not unbounded in any direction (the first half of the clause, that it misses the line $\mathbb{R}u_k$, is correct). Fix: split the clause — the set misses $\mathbb{R}u_k$ whenever $\lambda_k \le 0$, and it is unbounded along $u_k$ provided some $\lambda_j > 0$, i.e. provided the set is non-empty.
3. [minor] statement "Principal axes" (line 46): "the level set ... is a hyperboloid" is written for general $n$, but in $n=2$ the set is a hyperbola (a curve) and in $n=1$ a pair of points. Fix: say "a hyperboloid (a hyperbola when $n=2$)" or "a quadric of hyperbolic type".
4. [minor] statement "Definiteness tests", part 2 (line 53): Sylvester's criterion is stated for Hermitian $A$ and cited to Gelfand & Fomin §30, p. 127, where the criterion is stated only for a real quadratic form ("the descending principal minors ... of the matrix $\|a_{jk}\|$"). The Hermitian version is true and standard, but it is stronger than what the cited page says. Fix: attribute the real case to Gelfand & Fomin and mark the extension to Hermitian $A$ as ours, or add a source that states the Hermitian form.
5. [minor] remark "Traps", "Conventions" paragraph: "Some texts define the form with a factor $\tfrac12$ ... the eigenvalues then halve" is ambiguous about what is held fixed. With the matrix $A$ fixed the coefficients in the sum of squares halve, as the sentence intends; with the *form* fixed the representing matrix, and hence its eigenvalues, doubles. Fix: say which is held fixed.
