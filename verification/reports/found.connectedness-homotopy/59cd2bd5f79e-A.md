## Findings
1. [blocking] statement "Invariance, and the standard examples", item 3 (line 118): "Nonemptiness cannot be dropped: $\emptyset$ is convex but has no base point, so it is not path-connected and not simply connected." The claim that $\emptyset$ is not path-connected is false under this unit's own definition. Line 59 reads: "Say $X$ is **path-connected** when some path in $X$ joins $p$ to $q$, whichever pair $p, q \in X$ is named" - a condition universally quantified over pairs in $X$, hence vacuously satisfied by $\emptyset$. (Lee's definition on p. 608 is the same and equally vacuous.) This sentence is ours, not Lee's: Exercise A.67 says only that every star-shaped set is simply connected, so the deference rule does not apply. The conclusion drawn is right - $\emptyset$ is not simply connected - but for the other reason. Fix: "$\emptyset$ is convex, and vacuously path-connected, but simple connectivity also asks for a base point $q \in X$ at which $\pi_1(X, q)$ is trivial, and $\emptyset$ has none; so it is not simply connected. The star-shaped hypothesis carries nonemptiness with it, since a centre $c \in U$ is required." Alternatively, write nonemptiness into the definition at line 59 and say so there - but then item 1 of the path statement, item 3 of the connected statement and the path-component claims all need rereading, so the first fix is the cheaper one.
2. [blocking] frontmatter `prereqs` (line 7): the unit's definitions and statements rest on elementary group theory, which is neither defined here nor reachable from the single listed prerequisite. Line 101 asserts that the path classes of loops "is a group", and names its "neutral element" and the inverse $[f]^{-1} = [\bar f]$; line 101 and item 2 use "isomorphism"; item 1 (line 116) uses "group homomorphism" and composition of homomorphisms; item 4 (line 119) uses "infinite cyclic group" and $\cong \mathbb{Z}$; item 5 (lines 120-124) uses the direct product of groups. `found.continuity-homeomorphism` and its chain (`found.topological-spaces`, `found.sets-cardinality`) supply none of this, and none of it is standard undergraduate calculus or linear algebra, which is the only unlisted background `docs/STYLE_GUIDE.md` (line 8) permits. Fix: add `group.groups-subgroups` (group axioms, inverses, cyclic groups) and `group.homomorphisms-quotients` (homomorphism, isomorphism) to `prereqs`. Both exist in `content/map.yaml`, and `group.groups-subgroups` has `prereqs: []`, so neither introduces a cycle. If a forward reference across parts is unwanted, the alternative is to spell the four terms out in the fundamental-group block; it is the unexplained vocabulary that is the defect, not where it is fixed.
3. [source] statement "Properties of connected spaces", item 3 (line 49): "Any connected subset of $X$ sits inside one single component." This is Lee's Prop A.39(b), p. 607, in substance and almost in wording, and the unit reports it faithfully, so by `docs/contributing/source-authority.md` it does not fail the unit. I record that I believe the source statement is imprecise: $\emptyset$ is a connected subset under the definition at line 37 (it admits no separation, since both parts of a separation must be nonempty) and is contained in *every* component, so the uniqueness implied by "one single component" fails for $S = \emptyset$ whenever $X$ is disconnected. Lee's own Prop A.39(d) makes components nonempty, so $\emptyset$ is never itself a component and the gap is only in (b). Recorded with `node tools/discrepancy.mjs add found.connectedness-homotopy lee-2013 "Prop A.39(b), p. 607" ...`. One word - "nonempty" - would close it here too, if the drafter would rather not carry the source's imprecision.
