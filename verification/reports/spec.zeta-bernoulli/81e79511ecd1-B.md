## Findings
1. [minor] frontmatter (line 7): `asym.euler-maclaurin` is listed as a prerequisite, and `tools/check` warns that it comes later in the map. The dependency looks reversed: Euler-Maclaurin needs the Bernoulli numbers, and this unit only points forward to it (lines 93, 239). Fix: drop the prereq and keep the two `:ref` pointers, or let whoever owns `content/map.yaml` reorder; nothing in the text uses Euler-Maclaurin.
2. [minor] definition (line 61): the grouping bound is written `$2^{-k}+\cdots+(2^{k+1}-1)^{-1} \ge \tfrac12$` and attributed to Riley, Hobson and Bence p. 130, whose grouping runs $1/(2^k+1)+\cdots+1/2^{k+1}$ instead. Both groupings are correct and both have sum $\ge\tfrac12$ (ours has $2^k$ terms each $\ge 2^{-(k+1)}$), so this is not a wrong claim, but it is not literally the book's grouping. Fix: either shift the indices to match p. 130 or say "by a grouping of the same kind".
3. [minor] application (line 306): "the measured Stefan-Boltzmann constant". Since the 2019 SI redefinition $k$, $h$ and $c$ are exact, so $\sigma = 2\pi^5k^4/(15c^2h^3)$ is an exact derived constant; the agreement is by definition, not by measurement. The number itself is right. Fix: "the SI value of the Stefan-Boltzmann constant".
4. [minor] note (line 225): the bullet introduces $B^{\mathrm{A}}_k$ for Ahlfors' numbers but line 224 leaves the Arfken variant as $\widetilde B_k$; the sentence "Ahlfors' indexing agrees with the second variant" would read more sharply as $B^{\mathrm{A}}_k=\widetilde B_k$. Cosmetic only; the identity $B^{\mathrm{A}}_k=(-1)^{k-1}B_{2k}=\lvert B_{2k}\rvert$ checks out against Ahlfors p. 186.
