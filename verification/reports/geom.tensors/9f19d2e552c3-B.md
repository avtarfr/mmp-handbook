## Findings
1. [minor] remark "Where the hypotheses are used" (line 184): the counterexample says "take $A$ with components $(1,0)$ in every coordinate system". An array with the same components in every system is not a contravariant vector, so the object exhibited is not of the kind hypothesis 1 quantifies over. The conclusion is nevertheless right: with a single fixed $A$ the relation gives only $n$ linear constraints on the $n^2$ numbers $K_{ij}$, so a non-tensor $K$ can always be built (with a genuine vector whose unbarred components are $(1,0)$ the free columns are mixed up but the count is unchanged). Fix: say "weaken hypothesis 1 to a single fixed array $A^j=(1,0)$", or keep a genuine vector and argue by counting constraints.
2. [minor] definition "Tensors of type $(r,s)$" (line 95): symmetry is introduced "for a tensor of type $(0,2)$ or $(2,0)$" but written only as $T_{ij}=T_{ji}$. A $(2,0)$ tensor's components carry upper indices. Fix: write both, $T_{ij}=T_{ji}$ and $T^{ij}=T^{ji}$.
3. [minor] definition "Tensor product and contraction" (line 121): the text appeals to "Hassani's Example 26.1.8", which is on p. 787; the block's `src` lists only "pp. 784, 788". The example is correct and does concern the would-be trace of a type $(2,0)$ tensor ($A=e_1\otimes e_1+e_2\otimes e_1$, trace $1$ in one basis and $6$ in another), and the frontmatter range 784-788 covers it. Fix: add p. 787 to the block's `src`.
4. [minor] application (line 275): "In relativity the same reasoning identifies the four-potential as a four-vector from the fact that a scalar wave operator applied to it equals the four-current" carries no citation. The claim is correct, and Arfken, Weber and Harris make the structurally identical argument in Example 4.1.2, p. 213 (Newton's equations). Fix: cite p. 213, or mark the sentence as ours.
5. [minor] definition "General coordinates and the two bases" (line 44): "the two coincide only when the coordinates are Cartesian" — strictly, $e_i=e^i$ for all $i$ iff the coordinate frame is orthonormal, which means Cartesian up to a rigid motion. Harmless, but a reader may trip on a rotated Cartesian system.
